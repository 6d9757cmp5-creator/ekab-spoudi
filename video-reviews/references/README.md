# Ελεγμένες αναφορές για AI έλεγχο βίντεο

Κάθε κεφάλαιο χρειάζεται χωριστή επιστημονικά ελεγμένη πηγή, π.χ. `01-01.md`. Δεν χρησιμοποιούμε ως πηγή το σενάριο του AI που δημιούργησε το βίντεο.

Συμπληρώστε: «Μάθημα και κεφάλαιο», «Μαθησιακοί στόχοι», «Εξήγηση που πρέπει να περιέχει», «Σωστές απεικονίσεις/επισημάνσεις», «Κρίσιμες αντενδείξεις / επαγγελματικά όρια», «Πηγές:» με συγκεκριμένο επίσημο οδηγό/έκδοση/σελίδα. Διάρκεια μέχρι 20 λεπτά ανά βίντεο. Να γίνει ανθρώπινος έλεγχος ακρίβειας προτού χρησιμοποιηθεί για κριτική αξιολόγηση.

Προσοχή: Η παρουσία URL δεν είναι επαλήθευση της επιστημονικής ορθότητας. Αν δεν υπάρχουν τεκμηριωμένες πηγές, ο έλεγχος δεν μπορεί να θεωρηθεί ολοκληρωμένος.
