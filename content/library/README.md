# Εκπαιδευτικές πηγές και υλικό
Ο φάκελος αυτός είναι **ιδιοκτησία περιεχομένου**, όχι δεύτερο αντίγραφο της ύλης. Τα `/official_questions.json`, `/eoppep-source.pdf`, `/ECLASS_INVENTORY.json`, τα μαθήματα και οι σχετικές αναφορές εξακολουθούν να βρίσκονται στις ενεργές διαδρομές τους.

Προτεινόμενα metadata κάθε κεφαλαίου: ταυτότητα/ειδικότητα, ελληνικός τίτλος, πηγή, URL/έκδοση, ημερομηνία, επιστημονικός έλεγχος, γλώσσα εικόνας, δικαιώματα χρήσης και checksum. Τα παραπάνω δεν αποτελούν ακόμη συμπληρωμένα metadata για όλα τα κεφάλαια.

**Κανόνας:** Η μεταφορά repository δεν μεταβάλλει 247 κεφάλαια ΣΑΕΚ, 314 ερωτήσεις ΕΟΠΠΕΠ, απαντήσεις, σκορ ή καταστάσεις ελέγχου. Για δημοσίευση ιατρικών οδηγιών απαιτείται τεκμηριωμένος έλεγχος εκτός των τεχνικών tests.
