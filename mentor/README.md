# MENTOR OS — ενιαία δομή στο GitHub

**Κεντρικός φάκελος του κώδικα: `mentor/`**

Αυτή η οργάνωση είναι **αναδιάταξη αρχείων και όχι αλλαγή λειτουργιών**. Η αρχική οθόνη της ΕΚΑΒ Σπουδή και το εργαστήριο χρησιμοποιούν τον ίδιο κώδικα φωνής και χαρακτήρα μέσω των υποενοτήτων που ακολουθούν.

```text
mentor/
├── app/
│   ├── home.mjs             ← MENTOR στην αρχική σελίδα
│   └── lab.mjs              ← βασικό εργαστήριο / συζήτηση
├── avatar/
│   ├── live.mjs             ← εκφράσεις και κίνηση στόματος
│   ├── cinematic.mjs        ← προβολή / κινηματογραφική παρουσία
│   └── hologram.mjs         ← παλιότερος WebGL 3D renderer
├── voice/
│   └── speech.mjs           ← ενιαίος ελληνικός μηχανισμός εκφώνησης
├── modules/
│   ├── live.js              ← εκπαιδευτικές αποστολές
│   ├── ecg.js               ← εισαγωγική μελέτη ΗΚΓ
│   ├── oral.js              ← αυτοέλεγχος προφορικών
│   ├── scenarios.js         ← κατάλογος περιστατικών
│   ├── library.js           ← κατάλογος βιβλιογραφίας
│   └── readonly.js          ← αναζήτηση δημοσιευμένης ύλης
├── core/                    ← κανόνες, εκπαιδευτική μηχανή, session store
├── scenario-atlas/          ← ταξινομημένα σενάρια
├── library/                 ← κατάλογοι πηγών
└── real-avatar/             ← πηγαίος κώδικας νεότερου 3D χαρακτήρα
```

## Γιατί υπάρχουν ακόμα `mentor-*.html`, `mentor-*.css` και μικρά `mentor-*.js` στη ρίζα;

Η ΕΚΑΒ Σπουδή είναι στατικό site. Αυτές οι διαδρομές έχουν ήδη χρησιμοποιηθεί από **την αρχική οθόνη, σελιδοδείκτες, το service worker, την υπάρχουσα ιστοσελίδα και τις αυτοματοποιημένες δοκιμές**.

Για να μην σπάσουν:

- Τα **12 παλιά αρχεία εισόδου JS** λειτουργούν ως μικροί ανακατευθυντές κώδικα (`import` ή `export *`) στον ενιαίο φάκελο `mentor/`.
- Οι παλιές σελίδες HTML παραμένουν ως δημόσια entrypoints, όχι ως δεύτεροι ανεξάρτητοι Mentors.
- Οι στατικές CSS, WebP/GLB και τα ήδη κατασκευασμένα WebGL bundles παραμένουν προσωρινά στις δημόσιες διαδρομές τους, επειδή η μεταφορά τους χωρίς προσεκτική διόρθωση των URL θα μπορούσε να χαλάσει την εμφάνιση, τον 3D χαρακτήρα ή την offline λειτουργία.
- Τα παλιά classic scripts (π.χ. `mentor-adaptive.js`, `mentor-personal-v1.js`) απαιτούν σταδιακή μετατροπή σε modules ή προσεκτική συμβατότητα. Δεν κάνουμε ανεξέλεγκτη μετακίνηση.

**Μην διαγράψετε τους δημόσιους ανακατευθυντές**, ακόμη και όταν ο κύριος κώδικας βρίσκεται στο `mentor/`.

## Προστασία δεδομένων

Η αλλαγή δεν τροποποιεί:

- `index.html`, τις δημόσιες διευθύνσεις ή τα υπάρχοντα `href` / `src` των σελίδων
- Το `sw.js` αλλάζει **μόνο** για τη νέα έκδοση cache και την προφόρτωση των μεταφερμένων modules· δεν επηρεάζει περιεχόμενο, συγχρονισμό ή αποθηκευμένους βαθμούς.
- `app.js`, `progress.js`, `sync-local.js`, `sync-model.js`, `cloud-sync.js`
- `study-scheduler.js`, `saek-exam-engine.js`, `ai-grading-client.js`
- τις υπάρχουσες εγγραφές προόδου / βαθμολόγησης ΣΑΕΚ και ΕΟΠΠΕΠ

Ο νέος φάκελος φωνής δεν μοιράζεται νέο αποθηκευτικό χώρο ούτε αποκτά πρόσβαση στη βαθμολόγηση.

## Έλεγχος πριν την ενσωμάτωση

```sh
node --test scripts/test-mentor-unified-structure.mjs
node --test scripts/test-mentor-voice.mjs
node --test mentor-avatar-live.test.mjs
node --test scripts/test-mentor-cinematic.mjs
node --test scripts/test-mentor-3d.mjs
```

Ακόμη απαιτείται πραγματικός browser smoke test σε desktop/mobile για το `index.html` και το `mentor-lab.html`. Το branch της αναδιάταξης **δεν πρέπει να συγχωνευθεί** μέχρι να περάσουν οι δοκιμές.

## Επόμενη, ανεξάρτητη φάση της ίδιας αναδιάταξης

Μεταφορά των υπόλοιπων δημόσιων assets, CSS, source maps και classic scripts **μόνο** αφού γίνει αυτόματος έλεγχος URL resolution, offline caching και iOS Safari. Οι επίσημοι βαθμοί παραμένουν εκτός του scope σε όλα τα στάδια.
