# MENTOR OS · Ιατρική βιβλιοθήκη επαγγελματικού επιπέδου (draft v0.1)

**Ημερομηνία 29/10/2026. Στάδιο: δοκιμαστικό, μη επιστημονικά εγκεκριμένο.**

## Γιατί υπάρχει

Ένας χρήστης μπορεί να είναι μαθητευόμενος διασώστης, φοιτητής ή επαγγελματίας γιατρός. Ο Mentor δεν πρέπει να «απαντά σε όλα» όταν δεν έχει ελεγμένα στοιχεία. Το παρόν στάδιο προσθέτει **δομημένη, αναζητήσιμη ευρετηρίαση κλινικής βιβλιογραφίας**, όχι άδεια άσκησης ιατρικής, διάγνωση ή αυτόματο decision support.

- **17 ειδικότητες** και **51 πρωτότυπα εκπαιδευτικά ερωτήματα κλινικής συλλογιστικής**, από καρδιολογία, πνευμονολογία και νεφρολογία μέχρι εντατική, μαιευτική και φαρμακολογία.
- **14 επαληθευμένοι επίσημοι βιβλιογραφικοί κόμβοι**: MSD Professional, ESC (ενημερώσεις 2026), GINA 2026, GOLD 2026, KDIGO, ADA 2026, IDSA, ASH, ACOG, NICE, EMA, WHO, CDC και ERC 2025.
- Για κάθε ερώτημα: θέμα, οργανωμένο εκπαιδευτικό πλαίσιο, αναγκαίες πληροφορίες προς αξιολόγηση, **όρια συμπερασμάτων**, παραπομπές σε πρωτογενείς οργανισμούς και `review_status:human-review-pending`.
- Πραγματική αναζήτηση στα ελληνικά (με αφαίρεση τόνων), φίλτρα 17 ειδικοτήτων, και ειλικρινές **«Δεν βρέθηκε κατάλληλη καταχώριση»** όταν η βιβλιοθήκη δεν έχει επαρκές αποτέλεσμα.
- Σύνδεση με τον ήδη υπάρχοντα **προγραμματισμένο Mentor coach**: μεγάλες ερωτήσεις κλινικού περιεχομένου μπορούν να εμφανίσουν προκαταχωρισμένο, μη εγκεκριμένο εκπαιδευτικό πλαίσιο και clickable links. Οι απλές ερωτήσεις μελέτης συνεχίζουν να χρησιμοποιούν τις προηγούμενες 59 κάρτες.
- **Μηδέν** επεξεργασία προσωπικών δεδομένων ασθενών, αποστολή σε AI backend, εντολές φαρμάκων/δοσολογίας, αυτόματες ιατρικές πράξεις, μεταβολή βαθμών ΕΟΠΠΕΠ/ΣΑΕΚ ή σύνδεση cloud sync.

## Τι αποδεικνύεται και τι ΟΧΙ

1. Οι 14 επίσημοι σύνδεσμοι παρέχουν **πραγματική πύλη προς πολύ μεγαλύτερο όγκο επιστημονικής βιβλιογραφίας**, αλλά τα κείμενα από αυτούς **δεν έχουν εισαχθεί ως fulltext**, ούτε έχουν ελεγχθεί όλες οι επιμέρους οδηγίες ή ενότητες.
2. Οι 51 απαντήσεις είναι **πρωτότυπα εκπαιδευτικά πλαίσια**, όχι απόσπασμα επιστημονικής κατευθυντήριας οδηγίας. Οι παραπομπές είναι **θεματικές σε index/home pages** (citation granularity = `topical-guideline-index-not-claim-level`), άρα **δεν** έχουν κλινικά ελεγχθεί ανά ισχυρισμό.
3. Κανένα επιστημονικό κείμενο δεν έχει γίνει αυθεντική κλινική απάντηση από αδειοδοτημένο γιατρό. Ένας εξειδικευμένος ιατρός πρέπει να μπορεί να ελέγξει την πρωτογενή πηγή, τα ακριβή πρωτόκολλα και την εφαρμοσιμότητα στο πραγματικό περιβάλλον της Ελλάδας.
4. Οι κλινικές συστάσεις αλλάζουν. Για παράδειγμα, η ESC και η ADA παρέχουν πλέον οδηγίες 2026. Για θεραπεία ή διάγνωση απαιτείται έλεγχος της ακριβούς τελευταίας έκδοσης ανά θέμα.
5. Ούτε μεγάλος αριθμός βιβλίων ούτε ένα μεγάλο chatbot επιτρέπουν να παρουσιάζεται ο Mentor ως πραγματικός γιατρός. Η πλήρης λειτουργία για ερωτήσεις συναδέλφων απαιτεί ελεγχόμενο retrieval, citation-level evidence, μηχανισμό εκδόσεων, αβεβαιότητας, σύγκρουσης πηγών και ανεξάρτητη κλινική πιστοποίηση.

## Ασφαλής κατασκευή

- `sources.json` — επίσημοι σύνδεσμοι και δικαιώματα, με `content_ingested:false`.
- `reference-questions.json` — 51 πρωτότυπες ερωτήσεις/πλαίσια με `clinical_use_allowed:false`.
- `clinical-engine.mjs` — ντετερμινιστικό retrieval και απόρριψη πλαστών URLs, ψευδών εγκεκριμένων status ή άγνωστων πηγών.
- `clinical-ui.mjs` — φιλικό κινητό interface και fallback όταν η ερώτηση δεν καλύπτεται.
- `clinical-engine.test.mjs` — κάλυψη της δομής, της αναζήτησης, του gating, της σταθερότητας και των πηγών.

### Δοκιμές

```sh
node --test mentor/clinical-desk/clinical-engine.test.mjs
node --check mentor-lab.js
node scripts/verify-mentor-browser.mjs
```

Το browser smoke καλύπτει Chromium/WebKit, επιλογή ειδικότητας, παραπομπή KDIGO, ερώτημα στον Mentor, αβεβαιότητα και μη μετάλλαξη των υφιστάμενων βαθμών. Τα πράσινα tests **δεν** αποτελούν ανεξάρτητο κλινικό ή νομικό έλεγχο.

**Επόμενη πραγματική αναβάθμιση:** ανάκτηση από πραγματικά επιστημονικά εγκεκριμένες ενότητες με ακριβές `guideline_id/version/section` και αναφορές στις συγκεκριμένες προτάσεις — μετά από επιβεβαίωση δικαιωμάτων και ανθρώπινη ιατρική επιμέλεια.

**Δεν γίνεται merge του draft PR λόγω των automated tests.** Ισχύουν οι απαιτήσεις του `AGENTS.md`.
