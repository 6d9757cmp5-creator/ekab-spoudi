# MENTOR OS — σύνδεση επτά συγγραμμάτων (review-only)

**Κατάσταση: δοκιμαστικό branch — Όχι παραγωγή / Όχι ιατρική έγκριση.**

## Πραγματικό αποτέλεσμα

Έχουν αντιγραφεί **τα επτά πλήρη εξαγμένα κείμενα** από το draft PR #83 στον ξεχωριστό φάκελο `mentor/review-corpus/` του νέου branch, χωρίς επανεξαγωγή και χωρίς αλλαγή περιεχομένου. Τα ψηφιακά αποτυπώματα SHA-256 των αρχείων αντιπαραβάλλονται με το πρωτότυπο `mentor/review-corpus/manifest.json`.

Η καρτέλα **«Βιβλία · Έλεγχος»** του `mentor-lab.html` συνδέεται πραγματικά με τα αρχεία:
- Επιλέγεις **ένα** από τα επτά βιβλία.
- Γράφεις έναν όρο στα αγγλικά ή περιορισμένο ελληνικό τεχνικό όρο.
- Φορτώνεται **μόνο** το επιλεγμένο αρχείο, γίνεται έλεγχος SHA-256 και επαλήθευση αναγνωριστικών.
- Εμφανίζονται έως 6 πραγματικά, σύντομα αποσπάσματα (260 χαρακτήρες), κωδικός, θέση του εξαγμένου κειμένου και πραγματικός σύνδεσμος στον εκδότη.
- Ο ξεχωριστός προϋπάρχων προγραμματισμένος Mentor coach μπορεί να στέλνει έναν όρο σε αυτή την καρτέλα με το κουμπί «Αναζήτησε τον όρο στα βιβλία». **Δεν χρησιμοποιεί αυτά τα ανεπιβεβαίωτα δεδομένα για να συνθέτει ιατρικές απαντήσεις.**

## Καταγραφή δηλωμένων αδειών και επιταχυνόμενος έλεγχος (29/10/2026)

Ο κάτοχος του έργου **δήλωσε ρητά ότι έχει άδεια για όλα τα επτά συγγράμματα**, συμπεριλαμβανομένων του *OpenStax Medical-Surgical Nursing* και του *WHO/ICRC Basic Emergency Care*. Η δήλωση έχει καταγραφεί στο `mentor/review/rights-attestation.json`.

- Όλα τα επτά βιβλία εμφανίζονται πλέον στην **απομονωμένη βιβλιογραφική προεπισκόπηση**. Η αναζήτηση δεν παράγει ιατρικές απαντήσεις και δεν αποτελεί δημόσια παραγωγική δημοσίευση.
- Δεν έγινε ανεξάρτητη εξέταση εγγράφων αδειοδότησης. Η άδεια χρήσης (σύμφωνα με τη δήλωση) δεν ισοδυναμεί με κλινική έγκριση ή εξουσιοδότηση για κάθε τρόπο διάθεσης/εκπαίδευσης AI.
- Παραμένουν **μηδέν εγκεκριμένα αποσπάσματα για κλινική ανάκτηση από LLM**. `clinical_retrieval_enabled`, `ai_retrieval_allowed`, `model_training_allowed` και `production_publication_allowed` είναι `false`.
- Το `mentor/review/audit-corpus.mjs` ελέγχει SHA-256 και δημιουργεί **αναλυτική λίστα κλινικού ελέγχου** με δείγματα ανά θέμα. Τα 2.799 αποσπάσματα επιβεβαιώθηκαν τεχνικά ως προς την ακεραιότητά τους· 106 εγγραφές επιλέχθηκαν για στοχευμένη ανθρώπινη επιμέλεια. Αυτά **δεν** συνιστούν 106 ιατρικές εγκρίσεις.
- Πέντε Pressbooks κείμενα έχουν `whole-book` αντί για ακριβείς ενδείξεις κεφαλαίων. Χρειάζεται αποκατάσταση πλοήγησης και προέλευσης πριν την επιστημονική ενεργοποίηση.

Αποτελέσματα και λίστα εκκρεμοτήτων στα artifacts της ενέργειας **MENTOR seven-book review bridge** στο GitHub Actions.

## Σημαντικά όρια

- Και τα επτά κείμενα έχουν `review_status: draft`; μηδέν έχουν περάσει ανεξάρτητη ιατρική επιμέλεια.
- Η δημόσια εφαρμογή έχει μηδενική ενεργοποίηση κλινικής ανάκτησης: όλες οι εγγραφές του `source-index.json` έχουν `clinical_retrieval_enabled:false`.
- Η προβολή είναι **εσωτερικός βιβλιογραφικός έλεγχος**, όχι ιατρικός βοηθός. Καμία αυτόματη διάγνωση, συνταγογράφηση, επιλογή θεραπείας, κλινική διαλογή ή δημιουργία απαντήσεων AI.
- Η εξαγωγή HTML των πέντε Pressbooks εμφανίζει `whole-book` και δεν έχει αξιόπιστο δείκτη κεφαλαίου/σελίδας. Δεν κατασκευάζονται ψεύτικες παραπομπές κεφαλαίου.
- Στα δύο PDF οι ενδείξεις «PDF page n» αποτελούν ένδειξη εξαγωγής, όχι επιβεβαιωμένο επιστημονικό citation.
- Υπάρχει δήλωση του κατόχου για όλες τις άδειες· δεν έχουμε ελέγξει ανεξάρτητα τα αποδεικτικά, το ακριβές πεδίο των δικαιωμάτων ή τις επιμέρους εικόνες και εκδόσεις. Δεν έχει δημοσιευθεί εγκεκριμένη ιατρική βιβλιοθήκη.
- Δεν έχει πραγματοποιηθεί εκπαίδευση ή fine-tuning μοντέλου. Η πρόοδος ΣΑΕΚ/ΕΟΠΠΕΠ και οι grader/sync λειτουργίες παραμένουν ανεπηρέαστες.
- Το νέο review branch είναι προσβάσιμο στους συνεργάτες μέσω GitHub, αλλά **δεν πρέπει να συγχωνευτεί στο main** ώσπου να ολοκληρωθεί ο έλεγχος δικαιωμάτων και ανεξάρτητη ιατρική αξιολόγηση.

## Τεχνικός έλεγχος

```sh
node --test mentor/review/*.test.mjs
node --test mentor/core/*.test.mjs
```

Η ενσωματωμένη browser δοκιμή `scripts/verify-mentor-browser.mjs` καλύπτει πλήρη αναζήτηση πραγματικού βιβλίου σε κινητό Chromium/WebKit, ελληνικό όρο, SHA-256, παραπομπή, όριο αποσπάσματος, διατήρηση βαθμών ΕΟΠΠΕΠ και τη μετάβαση από τον Mentor coach.

## Επόμενο στάδιο

Επιμελημένο πέρασμα κεφαλαίων/ιατρικών πηγών, επιστημονικός έλεγχος και license audit ανά πηγή, δημιουργία εγκριμένου citation index, στη συνέχεια ξεχωριστό backend retrieval gateway για πραγματικό AI Mentor με επιβεβαίωση πηγών. Το chatbot θα αποκτήσει source-grounded απαντήσεις **μόνο όταν εγκριθούν πραγματικά αποσπάσματα**.
