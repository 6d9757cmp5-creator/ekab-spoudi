# MENTOR OS — Εργαστήριο αποστολών (Foundation v0.1)

**Κατάσταση: δοκιμαστικό πρωτότυπο, όχι ενεργή λειτουργία της κανονικής εφαρμογής.**

Αυτό το branch υλοποιεί το πρώτο ανεξάρτητο τμήμα του μελλοντικού MENTOR OS. Δεν τροποποιεί τα υπάρχοντα στοιχεία βαθμολόγησης, συγχρονισμού, εξετάσεων ή προόδου του «ΕΚΑΒ Σπουδή».

## Τι λειτουργεί στο δοκιμαστικό περιβάλλον

- Σελίδα mentor-lab.html + mentor-lab.css + mentor-lab.js με ελληνικό περιβάλλον «Αποστολή / Μνήμη / Διαδρομή».
- Δύο **συνθετικές** αποστολές: οικία με δύσπνοια και τροχαίο.
- Ντετερμινιστική μηχανή επιλογών για ασφάλεια σκηνής, οργανωμένη αρχική εκτίμηση, επικοινωνία και παράδοση. Οι λανθασμένες επιλογές παραμένουν στο ίδιο βήμα έως ότου διορθωθούν. Καμία προσομοίωση φαρμάκων, θεραπείας ή πραγματικής μεταβολής ζωτικών.
- Καταγραφή μόνο Mentor events, επαλήθευση replay, ανεξάρτητη σύνοψη εξάσκησης ανά δεξιότητα και σύντομη προτεινόμενη συνεδρία.
- Ξεχωριστή IndexedDB **ekab-mentor-v1**, με sessions/events/mastery/preferences. Τα δεδομένα είναι τοπικά, χωρίς cloud sync. Scope επισκέπτη ανά καρτέλα browser.
- Ενημέρωση και προσωρινή λειτουργία στη μνήμη αν IndexedDB δεν είναι διαθέσιμη.
- Εξαγωγή όλων των Mentor sessions και διαγραφή μόνο του τρέχοντος scope.
- Προαιρετική, με ρητό πάτημα, ανάγνωση συνοπτικών καταγραφών προηγούμενης μελέτης ΣΑΕΚ/ΕΟΠΠΕΠ.
- Εμφανής σήμανση ότι δεν έχουν υλοποιηθεί ακόμη AI συνομιλία, 3D anatomy, ECG lab, ιατρική ομάδα, πολλαπλοί ασθενείς, εξοπλισμός ή προφορικές εξετάσεις.

## Δοκιμή σε υπολογιστή

1. Κατέβασε το branch **feature/mentor-scenario-foundation** από το GitHub.
2. Στη ρίζα του repository εκτέλεσε: python3 -m http.server 8000
3. Άνοιξε: http://localhost:8000/mentor-lab.html
4. Επίλεξε αποστολή, κάνε επιλογές και έλεγξε Μνήμη/Διαδρομή.
5. Εκτέλεσε: node --test mentor/core/*.test.mjs

Μην ανοίξεις το HTML ως file:// — τα ES modules απαιτούν HTTP(S).

## Όρια και ασφάλεια

- Οι περιπτώσεις είναι **fictional, clinical-review-pending**, όχι πραγματικά περιστατικά ή κλινικές οδηγίες. Δεν υποστηρίζουν καθοδήγηση πραγματικών επεμβάσεων ή επίσημη βαθμολόγηση.
- Δεν γίνεται AI εκπαίδευση ούτε ανάκτηση από τα επτά ακαδημαϊκά βιβλία του **draft PR #83** (όλα ακόμη σε κλινικό έλεγχο).
- Το ανεξάρτητο **draft PR #22** περιέχει παλαιότερο read-only prototype και δεν συγχωνεύθηκε.
- Επόμενοι έλεγχοι: browser/iOS QA, πραγματική δοκιμή IndexedDB και multi-tab, έγκριση κλινικού ελεγκτή, συνδεδεμένη γνώση με πηγές, έλεγχος πλαισίου ελληνικών αρμοδιοτήτων.

## Προστασία της παλιάς εφαρμογής

Δεν αλλάζουν: ai-grading-client.js, ai-grading-config.js, functions/answer-grader, workers/answer-grader, saek-exam-engine.js, study-scheduler.js, sync-local.js, sync-model.js, cloud-sync.js, progress.js, app.js, index.html, official_questions.json ή οι προσωπικές σημειώσεις.

Ο Mentor δεν γράφει βαθμούς ΣΑΕΚ/ΕΟΠΠΕΠ, δεν χρησιμοποιεί το παλιό cloud sync schema και δεν μετατρέπει εξάσκηση σε πιστοποιημένη ικανότητα.

## Έλεγχοι

Το workflow .github/workflows/mentor-foundation-verify.yml εκτελεί tests σύνταξης, unit tests του Mentor, απαγόρευση αλλαγών σε προστατευμένα αρχεία και υπάρχον release smoke. Επιτυχία CI **δεν** σημαίνει ιατρική/οπτική πιστοποίηση ή ετοιμότητα παραγωγής.

**Επόμενο milestone:** browser QA, έγκριση των σεναρίων και επέκταση της κοινής μηχανής για διαλογή και εικονικό εξοπλισμό, έπειτα ECG και 3D ανατομία.
