## Προσωπικό πλάνο από το παλιό PR #22 (μετεγκατάσταση)

Η δοκιμαστική καρτέλα **Διαδρομή** περιλαμβάνει πλέον:
- Επιλογή προσωπικών στόχων **ΣΑΕΚ / ΕΟΠΠΕΠ / Σεμινάρια**· ο χρήστης μπορεί να μην επιλέξει κανέναν, χωρίς να ενεργοποιείται αυθαίρετος στόχος.
- Διάρκεια **10 / 15 / 25 / 30 λεπτών** και επιλογή **καθοδήγησης / εξάσκησης / δοκιμαστικής αυτοαξιολόγησης**. Οι χρόνοι είναι ενδεικτική κατανομή, όχι ιατρική αξιολόγηση.
- Τοπική αποθήκευση μόνο στο namespace προτιμήσεων Mentor `ekab.mentor.preferences.v1`, με συμβατότητα προς τις παλιές επιλογές του PR #22. Ούτε οι βαθμολογίες ούτε το cloud sync ΣΑΕΚ/ΕΟΠΠΕΠ τροποποιούνται.
- Πραγματικά links στις υπάρχουσες εκπαιδευτικές ενότητες και ανεξάρτητη **προαιρετική, μόνο για ανάγνωση** προβολή συνοπτικής παλιάς προόδου, χωρίς ισχυρισμό επιβεβαιωμένης γνώσης.
- Έλεγχοι `mentor/core/study-goals.test.mjs` και διευρυμένο mobile Chromium smoke σε `scripts/verify-mentor-browser.mjs` για ανανέωση/αποθήκευση και προστασία προόδου.

Η μετεγκατάσταση δεν δημοσιεύει αυτόματα τον Mentor, δεν επαναφέρει το παλιό tracker του PR #22 πάνω στη νέα αρχική οθόνη και δεν αλλάζει υπάρχουσα βαθμολόγηση. Ο έλεγχος των PR και το κλινικό review παραμένουν ξεχωριστές προϋποθέσεις.

## Κοινός εκπαιδευτικός πυρήνας

- `mentor/core/workflow.mjs` — κοινό, ντετερμινιστικό βήμα αποφάσεων· χρησιμοποιείται από τις αρχικές αποστολές μέσω `engine.mjs` και από τα νέα εργαστήρια μέσω `activity-engine.mjs`.
- `mentor/core/activities.mjs` — 5 δομημένες δραστηριότητες, με `source_status: clinical-review-pending` και σταθερά αναγνωριστικά.
- `mentor/core/activity-engine.mjs` — κατάσταση, απαιτούμενη καταμέτρηση όλων των εμπλεκομένων, event log, ανασύνθεση και επαλήθευση αλλοιώσεων, επαναλήψιμες μεταβάσεις.
- `mentor/activities-ui.mjs` — responsive διαδραστικά panels σε `mentor-lab.html`.
- `mentor/core/activity-store.mjs` — αποκλειστικά δική του IndexedDB `ekab-mentor-activities-v1`, ξεχωριστή και από την IndexedDB των αρχικών δοκιμών `ekab-mentor-v1`.
- `mentor-lab.js` — ενώνει τα τρία εργαστήρια και τη μνήμη Mentor. Η εξαγωγή χρησιμοποιεί schema `ekab-mentor-export-v2`, που περιλαμβάνει αμφότερα τα session sets.

**Δεν** υπάρχει ακόμη αποδεδειγμένη φυσιολογική προσομοίωση, χρωματική/αλγοριθμική ιατρική διαλογή, χρήση φαρμάκων ή πραγματική συσκευή. Ο Mentor δεν εκπαιδεύεται αυτομάτως από αρχεία· το draft PR #83 περιέχει επτά εξαγμένα βιβλία που αναμένουν επιστημονική επιμέλεια και δεν συνδέονται εδώ.

## Οδηγίες δοκιμής

1. Checkout στο branch `feature/mentor-scenario-foundation`.
2. Από τη ρίζα: `python3 -m http.server 8000`.
3. Άνοιγμα `http://localhost:8000/mentor-lab.html`.
4. Πάτησε **Αποστολή** και άλλαξε λειτουργία: **ΕΚΑΒ Live**, **Πολλαπλοί εμπλεκόμενοι**, **Εργαστήριο εξοπλισμού**.
5. Δοκίμασε μία λανθασμένη και μία σωστή επιλογή, ολοκλήρωσε μια καταμέτρηση, κάνε refresh και έλεγξε τις ενότητες Μνήμη και Διαδρομή.
6. Δοκίμασε εξαγωγή/διαγραφή των δεδομένων Mentor και επιβεβαίωσε ότι τα υπάρχοντα στοιχεία ΣΑΕΚ/ΕΟΠΠΕΠ δεν επηρεάζονται.

Για τεχνικές δοκιμές: `node --test mentor/core/*.test.mjs` και `node scripts/verify-mentor-browser.mjs` (το τελευταίο απαιτεί Playwright/Chromium και local server του script). Οι GitHub Actions `Mentor scenario foundation`, `Mentor browser simulation`, `Media publication gate` και `Release quality smoke checks` καλύπτουν το PR.

## Ασφάλεια ιστορικού και δικαιωμάτων

- **Χωρίς καμία τροποποίηση** του υπάρχοντος AI grading (`ai-grading-client.js`, `functions/answer-grader/`, `workers/answer-grader/`) ή των αρχείων `app.js`, `progress.js`, `sync-local.js`, `sync-model.js`, `cloud-sync.js`, `study-scheduler.js`, `notes-store.js`, `index.html`.
- Κανένα event του Mentor δεν εγγράφεται σε βαθμολογία ΣΑΕΚ ή ΕΟΠΠΕΠ. Η προαιρετική εμφάνιση παλαιών μετρητών είναι **μόνο ανάγνωση**.
- Guest scope ανά browser tab· τα sessions βρίσκονται τοπικά, χωρίς server ή cloud sync. Έλεγχοι λογαριασμού/πολλαπλών καρτελών θα χρειαστούν πριν από production release.
- Το CI πραγματικού Chromium με viewport κινητού ελέγχει επιλογές, καταμέτρηση, αποθήκευση μετά από refresh, εξαγωγή και διαγραφή. **Δεν** έχει αντικαταστήσει δοκιμές σε πραγματικό iPhone/Safari ή ανεξάρτητη ιατρική επιμέλεια.
- Τα νέα κείμενα είναι **συνθετικές εκπαιδευτικές ασκήσεις**. Δεν πρέπει να θεωρηθούν εγκεκριμένες κλινικές οδηγίες ή να χρησιμοποιηθούν για πραγματική φροντίδα ασθενή.

## Απαραίτητο πριν τη δημοσίευση

1. Εξειδικευμένος κλινικός έλεγχος κάθε περιεχομένου, ακριβών ελληνικών όρων, αρμοδιοτήτων και τεκμηρίωσης.
2. Μοντελοποίηση πραγματικής διαλογής μόνο βάσει συγκεκριμένου ισχύοντος πρωτοκόλλου και κλινικά ελεγμένων fixtures.
3. Διαδραστικοί χειρισμοί ιατρικών συσκευών μόνο με τεκμηριωμένα εγχειρίδια συγκεκριμένου μοντέλου και έγκριση ειδικού.
4. Browser και προσβασιμότητα (κινητό Safari, offline, πολλαπλές καρτέλες, πολλαπλοί λογαριασμοί), δεδομένα/backup migration και rollback.
5. Σταδιακή ξεχωριστή σύνδεση σε **εγκεκριμένη** βιβλιογραφική ανάκτηση, μετά ECG Lab και 3D Anatomy με προέλευση μοντέλων/δειγμάτων.
