# ATLA · Διεθνής σύγκριση ιατρικών προσομοιωτών και επιτρεπτά 3D assets
**Ημερομηνία:** 2026-11-09 · **Πεδίο:** Προσομοιωτής Ασθενών ΕΚΑΒ Σπουδή · **Κατάσταση:** τεχνικό benchmark, όχι κλινική πιστοποίηση.

## Μεθοδολογία
Οι λειτουργίες τρίτων βασίζονται σε δημοσιευμένες περιγραφές των κατασκευαστών, όχι σε ανεξάρτητες δοκιμές των κλειστών εφαρμογών. Τα χαρακτηριστικά του ATLA βασίζονται στα υπάρχοντα modules/tests. Δεν έγινε εξαγωγή εμπορικού κώδικα, screenshot ή μοντέλου. Η εκπαιδευτική χρήση δεν συνεπάγεται γενικό δικαίωμα αντιγραφής.

## Πραγματικό backlog, με σειρά
1. **P0 — Ακεραιότητα στοιχείων:** ξεχωριστές αποδείξεις Α/Β, εμφανή κενά, δομημένη εκπαιδευτική παράδοση, απαγόρευση επινοημένων ζωτικών ή θεραπευτικής σύστασης. Node unit και browser regression για απομόνωση δεδομένων και μη καταγραφή απλής προβολής/αντιγραφής.
2. **P1 — Οπτική αληθοφάνεια:** CC0 PBR άσφαλτος/πεζοδρόμια/δωμάτια, εξοπλισμός και φωτισμός σε **δικό μας ενιαίο 3D renderer**, όχι εξωτερικό viewer. Έλεγχος αναλογιών, frame rate, shaders, φόρτωσης, offline και πραγματικών screenshots 390×844 / 820×1180 / 1440×900 πριν από ενεργοποίηση. Το παρόν έγγραφο **δεν** ενσωματώνει textures.
3. **P1 — Ποιότητα ανθρωπίνων assets:** τεκμηριωμένη προέλευση ειδικά για skin PBR/rigging/animation, ρεαλιστικές αναλογίες και fallback. Ένα GLB ή εκπαιδευτική κίνηση δεν αποτελεί ιατρικά αληθή φυσιολογία.
4. **P2 — Δυναμικές διαδράσεις/κλινικά σενάρια:** απαιτείται ανεξάρτητη επιστημονική έγκριση, ξεκάθαρα αρχεία πηγών και validated state transitions. Μέχρι τότε παραμένουν ανενεργά/συνθετικά, χωρίς επινοημένες θεραπείες.
5. **P2 — Εκπαιδευτική απόδοση:** guided decisions, debrief, μελέτη πραγματικής χρήσης σε κινητά, έλεγχος με σπουδαστές και ανεξάρτητη αξιολόγηση.

## Πηγές και άδειες: υποχρεωτική απόφαση ανά συγκεκριμένο αρχείο
| Πηγή | Επίσημα δικαιώματα | Ασφαλής χρήση |
|---|---|---|
| [Poly Haven](https://polyhaven.com/license) | Τα 3D assets, HDRIs και textures του καταλόγου CC0· το website/λογότυπα/κείμενα δεν καλύπτονται αυτόματα. | Σύνδεση upstream URL, έκδοση, checksum, optimization, τοπικό asset και επιθεώρηση. |
| [ambientCG](https://docs.ambientcg.com/license/) | Assets CC0 1.0, αλλαγή και αναδιανομή επιτρέπεται. | Συγκεκριμένο PBR material με ID, πηγή, SHA-256 και ημερομηνία. |
| [NIH 3D](https://3d.nih.gov/terms) | Οι εγγραφές έχουν **διαφορετικές άδειες** και το NIH απαιτεί έλεγχο για κάθε μοντέλο. | Καμία αθρόα εισαγωγή: δικαιώματα/προέλευση/επιστημονικό audit ανά asset. |
| [3D Slicer](https://slicer.org/commercial-use.html) | BSD-style άδεια λογισμικού, όχι πιστοποίηση FDA. | Μελέτη/χρήση συμβατών τμημάτων, χωρίς να αποδίδεται αυτομάτως η ίδια άδεια στα ανεξάρτητα ιατρικά datasets. |
| [Sketchfab](https://sketchfab.com/developers/download-api/guidelines) | Άδειες ανά μοντέλο, συνήθως attribution· download API με login/όρους. | Μόνο με ρητό έλεγχο συγκεκριμένου author, URL, άδειας, όρων download, αποδιδόμενων credits. |
| [OpenLabyrinth](https://github.com/olab/Open-Labyrinth) | GPL-3.0. | Αρχιτεκτονική αναφορά· όχι αυτούσια αντιγραφή κώδικα χωρίς ειδική νομικοτεχνική συμβατότητα. |

Πριν από κάθε εισαγωγή 3D asset: **source URL, δημιουργός, ακριβής άδεια/URL, source revision, SHA-256, ημερομηνία, attribution, size/LOD, ελεγμένη χρηστικότητα mobile, κλινική καταλληλότητα όπου αφορά ανατομία**. Προσοχή σε trademarks, προσωπικά δεδομένα, λανθασμένα/AI-generated ιατρικά μοντέλα. Δεν δημιουργούμε δεύτερο NIH registry: ο κοινός κατάλογος ATLA παραμένει η πηγή αλήθειας.

**Απαγορεύεται** να παρουσιαστούν ως πρωτότυπα εμπορικές εικόνες/UI, να εξαχθούν κλειστά assets ή να θεωρηθεί η χρήση εκπαιδευτική γενικό δικαίωμα αντιγραφής. CC-BY συνεπάγεται attribution, CC-BY-SA πιθανή υποχρέωση share-alike, NC/ND ειδικούς περιορισμούς. Άγνωστη άδεια → **δεν εισάγεται**.
