## 2. Υφιστάμενη, επιθεωρημένη κατάσταση του έργου

- [ENGINE contract](./README.md) ορίζει **ένα** σύστημα, adapter για αρχικά ΣΑΕΚ, και πύλη δημοσίευσης (sourceHash, coverage/clinical approvals). Ο παραγωγικός renderer **δεν έχει υλοποιηθεί**.
- [Worker package](../../workers/educational-animation/package.json) δηλώνει pinned `remotion=4.0.539`, `@remotion/renderer=4.0.539`, `react=19.3.1`, `react-dom=19.3.1`. Δεν δηλώνει ακόμη `three`, `@react-three/fiber`, `@remotion/three`.
- [Worker config](../../workers/educational-animation/worker.config.json): `VIDEO_GENERATION_ENABLED=false`, `gpuProviderConfigured=false`, `remoteDispatchEnabled=false`.
- [worker.mjs](../../workers/educational-animation/worker.mjs): η εντολή render/AI/TTS/dispatch/publish απορρίπτεται εκ προθέσεως. Η προετοιμασία αρχείων/μοντέλων, hashes και εκτίμηση απαιτήσεων **δεν ισοδυναμούν με παραγωγή βίντεο**.
- Η τεκμηρίωση Dell λέει ότι FFmpeg, Remotion Renderer και Chromium προετοιμάστηκαν, αλλά **δεν επιβεβαιώνει εγκατάσταση Blender ή λειτουργικό 3D render** στο συγκεκριμένο μηχάνημα.
- [3D Anatomy Registry](../../tools/anatomy-3d/resources/README.md) περιλαμβάνει HRA/HuBMAP και BodyParts3D. Το κάθε μοντέλο χρειάζεται τεκμηρίωση provenance, αδειών για παράγωγα βίντεο, σωστού ανατομικού αντιστοιχισμού και, όπου απαιτείται, ανθρώπινο κλινικό έλεγχο. Στατικά 3D meshes ≠ επικυρωμένη κινούμενη φυσιολογία.

## 3. Αποδεκτή αρχιτεκτονική (χωρίς δεύτερο ENGINE)

1. **Εισαγωγή εγκεκριμένου περιεχομένου:** ανά κεφάλαιο `sourceId` και `sourceHash` + στόχοι, ελληνικό κείμενο/πηγές.
2. **Επιλογή asset:** ήδη υφιστάμενο 3D manifest, συγκεκριμένο τοπικό αρχείο/έκδοση/SHA-256, ακριβής άδεια και τεκμηριωμένα δικαιώματα τελικής δημοσίευσης.
3. **Blender ως *εξωτερικός εκτελέσιμος renderer*:** ξεχωριστό `.blend`, `.glb`, scripts για κινήσεις/κάμερα, υπολογισμός 3D frames ή export κινήσεων· χωρίς αντιγραφή του Blender GPL core στον JavaScript worker.
4. **Three.js + React Three Fiber + @remotion/three:** σύνθεση τρισδιάστατων σκηνών και συγχρονισμένη κίνηση σε γνωστά καρέ. Pinned packages με άδειες στον dependency manifest.
5. **Remotion core + renderer:** χρονοσειρά, ελληνικοί υπότιτλοι και αφήγηση από επιτρεπτή πηγή, ένωση render και εξαγωγή MP4 σε απομονωμένο render-worker, όχι μέσα στο static GitHub Pages/browser.
6. **Πύλη δημοσίευσης:** ισχύοντες source hashes, τεκμηρίωση κάλυψης, αδειών/αποδόσεων, ανεξάρτητος ιατρικός έλεγχος όπου απαιτείται, καρέ/απόδοση/πραγματική συσκευή και έγκριση δημοσίευσης. Δεν παρακάμπτουμε το feature lock.

## 4. Κόστη και κόκκινες γραμμές

- Το Blender και Three.js δεν απαιτούν συνδρομή. Το Remotion μπορεί να χρησιμοποιείται δωρεάν μόνο **αν** πληρούνται τα κριτήρια του συγκεκριμένου licensee. Για μη επιλέξιμους φορείς ισχύουν επαγγελματικές χρεώσεις ([τιμές](https://www.remotion.dev/docs/license/pricing)); η μεταγενέστερη υπηρεσία video generator χρειάζεται επανέλεγχο όρων και κατηγορίας. Δεν έχουν επαληθευτεί ειδικά συμβόλαια.
- Rendering hardware/cloud, AI voice/TTS και δικαιώματα τρίτων assets μπορεί να έχουν δικά τους κόστη.
- Δεν είναι εφικτό να αντιγράψουμε δύο *ολόκληρα* προγράμματα και να υποσχεθούμε αυτόματα αντίστοιχη ποιότητα, συμβατότητα ή απόδοση. **Απόδειξη λειτουργίας απαιτεί παραγωγή/έλεγχο πραγματικού πιλοτικού βίντεο.**
- Απαγορεύεται η υποκατάσταση πραγματικής ανατομίας/κινήσεων με απλώς πειστικά αλλά επιστημονικά μη επιβεβαιωμένα πλάνα.
