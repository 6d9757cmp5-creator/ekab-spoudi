# ΕΚΑΒ Σπουδή — Άδεια και προέλευση εξωτερικού κώδικα
Ημερομηνία: 2026-10-30

## Επαληθευμένος εξωτερικός κώδικας (πραγματική χρήση)
- Έργο: **Virtual Standardized Patient Simulator**.
- Δημιουργός: Igor Gembitsky.
- Repository: https://github.com/igembitsky/virtual-standardized-patient
- Αρχείο πηγής: `app/index.html`, συναρτήσεις `wrap` και `download` (βοηθητικός κώδικας μορφοποίησης/εξαγωγής αναφοράς).
- Άδεια: **MIT License**, πλήρες αντίγραφο στο `third_party/virtual-standardized-patient/LICENSE`. Οι δηλώσεις copyright και άδειας διατηρούνται.
- Αλλαγές: προσαρμοσμένες σε ελληνικά, αποκλειστικά συνθετικά εκπαιδευτικά MENTOR DEBRIEF `.txt`. Οι λειτουργίες σύνθεσης έκθεσης, διαχωρισμού ρόλων, ασφάλειας και ενσωμάτωσης είναι νέος κώδικας του ΕΚΑΒ Σπουδή.

## Πρωτότυπος κώδικας της εφαρμογής
- `mentor-patient-interview.mjs`: πρωτότυπος μηχανισμός πεπερασμένης εκπαιδευτικής συνέντευξης, εμπνευσμένος από τη γενική ιδέα εικονικών ασθενών. **Δεν είναι αντιγραφή** ιατρικών ιστορικών, κλινικών σεναρίων ή μηχανισμού AI τρίτων.
- `mentor-protocol-suite.mjs`: ο ίδιος MENTOR OS συνδέει ερωτήσεις, εκπαιδευτική συνέντευξη, τοπικό ιστορικό και ενιαίο DEBRIEF.
- `mentor-scenario-paths.mjs`: πρωτότυπο συνθετικό περιεχόμενο 18 θεμάτων × 3 επίπεδα πρώτων βοηθειών / διασώστη / ιατρού.

## Άλλοι διεθνείς πάροχοι
Οι λειτουργίες των **JRCALC, Pocket Prep, MedicTests, Body Interact** χρησιμεύουν ως σχεδιαστικά σημεία αναφοράς. Δεν έχουν μεταφερθεί εδώ κλειστά binaries, εσωτερικές βιβλιοθήκες, ιδιόκτητες ερωτήσεις, συνδρομητικά πρωτόκολλα ή προσωπικά/κλινικά δεδομένα. Η δήλωση του ιδιοκτήτη ότι κατέχει άδεια δεν ισοδυναμεί με τεχνική πρόσβαση σε μη δημόσιο πηγαίο κώδικα. Τυχόν συγκεκριμένη ενσωμάτωση ακολουθεί τους όρους του αντίστοιχου παραχωρημένου κώδικα και γίνεται με αρχείο προέλευσης/άδειας στο repository.

## Όρια
Δεν υπάρχει ακόμη επικυρωμένος ψηφιακός ασθενής με δυναμική φυσιολογία, θεραπευτικός αλγόριθμος, διάγνωση, AI συνομιλία ή άδεια άσκησης ιατρικής από τον MENTOR. Εκπαιδευτικές ασκήσεις και συνεντεύξεις δεν χρησιμοποιούνται για πραγματική φροντίδα ασθενών.

## Επαλήθευση
- 54 διαφορετικοί συνδυασμοί εκπαιδευτικού θέματος × μαθησιακού ρόλου ελέγχθηκαν για τη ντετερμινιστική ροή.
- JavaScript syntax και unit tests περιλαμβάνονται στο GitHub Actions `.github/workflows/app-load.yml`.
- Έλεγχος εκκίνησης κινητού/desktop στο Playwright smoke workflow. Η ολοκλήρωση του workflow πρέπει να επιβεβαιωθεί από το GitHub Actions πριν δηλωθεί πλήρης επιτυχία.
