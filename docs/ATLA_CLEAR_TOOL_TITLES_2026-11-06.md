# ATLA — Ενιαίοι ρόλοι εργαλείων και σαφείς ελληνικοί τίτλοι (06/11/2026)

## Απόφαση ονοματοδοσίας
Οι τίτλοι που βλέπει ο μαθητής πρέπει να εξηγούν αμέσως τη λειτουργία. Οι σύντομες τελικές ονομασίες και τα ακρωνύμια θα αποφασιστούν αργότερα. **ATLA** παραμένει το όνομα της πλατφόρμας· κανένα προσωρινό εκπαιδευτικό label δεν αποτελεί νέο προϊόν ή engine.

| Εμφανιζόμενος ελληνικός τίτλος | Ρόλος | Μοναδική πηγή λειτουργίας |
| --- | --- | --- |
| Προσωπικός Εκπαιδευτής | Εκπαιδευτικός βοηθός | `atla/assistant.mjs` μέσω υπάρχοντος MENTOR AI adapter |
| Τρισδιάστατη Ανατομία | Ανατομικός viewer | `tools/anatomy-3d/hires-anatomy.js`, δημόσια διεύθυνση `ui-tools/anatomy-3d/index.html` |
| Πλήρης Ανατομικός Άτλας | Επιλογή και προβολή BodyParts3D 4.0 / 4.3 | `ui-tools/anatomy-full-atlas.html`, διακριτός heavy atlas, όχι δεύτερη εφαρμογή εκμάθησης |
| Βιβλιοθήκη 3D Μοντέλων | Προεπισκόπηση πολλών πηγών / αδειών | `ui-tools/atla-resource-preview.html` + `tools/atla-ai/model-preview.mjs` |
| Προσομοιωτής Ασθενών | Συνθετικά κλινικά περιστατικά | `tools/patient-simulator/`, δημόσια διεύθυνση `mentor-next.html` |
| Κλασική Προσομοίωση Περιστατικού | Διατηρούμενη παλαιότερη αποστολή | `mentor-live.html`, δεν αφαιρείται χωρίς κάλυψη λειτουργιών και μεταφορά |
| Εργαστήριο ΗΚΓ | Εκπαιδευτική κυματομορφή | `tools/ecg-lab/` (μοναδική γεννήτρια) |
| Εξάσκηση σε Πρωτόκολλα | Διαδραστική εκπαιδευτική άσκηση | `mentor-protocol-suite.html` |
| Ανασκόπηση Αποστολής | Ανατροφοδότηση υπάρχοντος περιστατικού | Μέσα στον αντίστοιχο προσομοιωτή, όχι νέα εφαρμογή |

## Ενοποιήσεις και προστασίες
- Ο κύριος ανατομικός viewer είναι κοινός στις δύο ιστορικές HTML εισόδους. Δεν διαγράφουμε / ανακατευθύνουμε βίαια καμία: υπάρχουν παλαιά URL, ειδικοί σύνδεσμοι BioDigital, βαθιές παραπομπές από κεφάλαια, CSS και τεχνικές δοκιμές.
- ATLA/ATLAS/MENΤOR: ο μεταβατικός κώδικας διατηρείται ως adapter και παλαιές προσβάσεις. Η βασική μετάβαση ενσωματώθηκε στο PR #197. Δεν δημιουργείται δεύτερος AI backend ή grader.
- Η βιβλιοθήκη `tools/atla-ai/resources/model-library.json` και ο adapter `tools/atla-ai/nih3d-library.mjs` αποτελούν κοινή πηγή επιλογής. Η μεγάλη συλλογή BodyParts3D και το ανατομικό μοντέλο του Cockpit **δεν** συγχωνεύονται σε μία σκηνή: διαφέρουν σε στόχο, μνήμη, άδεια και επιστημονικό επίπεδο.
- Οι ήδη χωριστοί μηχανισμοί Anatomy Lab και Clinical Cockpit **μένουν χωριστοί**. Επαναχρησιμοποιούν υπηρεσίες/πηγές χωρίς αντιγραφή engine ή αλλαγή κλινικών δεδομένων.
- Οι ορατοί τίτλοι ανανεώνονται σε δημόσιες/ιστορικές οθόνες, αλλά **URL, ids, datasets, grade/memory keys, μοντέλα, πρωτόκολλα και αποθήκευση μένουν αμετάβλητα**.

## Επαλήθευση και εκκρεμότητες
- Ελεγμένα στοχευμένα αντικατασταθέντα labels και αμετάβλητα ids/URLs πριν από commit.
- Η υπάρχουσα στατική σουίτα `scripts/verify-atla-greek-ui.mjs` και το browser smoke `scripts/verify-atla-greek-ui-browser.mjs` ενημερώθηκαν για τους νέους τίτλους.
- Απαιτούνται πράσινα CI, οπτικός έλεγχος desktop / mobile, ιδιαίτερα για το μήκος των ελληνικών τίτλων, πριν από merge/deploy.
- Δεν πιστοποιεί την ανατομική ή κλινική ακρίβεια ούτε ολοκληρώνει το εξαντλητικό audit παλαιού κώδικα. Δεν συνιστά επιστημονική έγκριση.
