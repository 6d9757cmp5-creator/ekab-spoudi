# ATLA — Περιγραφικοί ελληνικοί τίτλοι και ασφαλείς κοινές είσοδοι (06/11/2026)

## Προσωρινή ονοματοδοσία, όχι τελικά ονόματα μαθητή
Τα παρόντα ονόματα εξηγούν με απλά ελληνικά τη λειτουργία. Η τελική ονοματοδοσία/συντομογραφίες που θα βλέπει ο μαθητής **αναβάλλονται** και δεν αλλάζουν εδώ τεχνικά IDs, routes, stores ή API.

| Περιγραφικός τίτλος | Μία είσοδος | Πραγματική λειτουργία / όριο |
|---|---|---|
| Μαθήματα και εργαλεία Διασώστη | `paramedic.html` | Κατάλογος, όχι δεύτερη πλατφόρμα ή αντίγραφο εργαλείων |
| Τρισδιάστατη ανατομία ανθρώπινου σώματος | `ui-tools/anatomy-3d/index.html` | Ενιαίος ενεργός viewer `tools/anatomy-3d/hires-anatomy.js` |
| Λεπτομερής 3D άτλας ανθρώπινου σώματος | `ui-tools/anatomy-full-atlas.html` | Προαιρετική λεπτομερής προβολή BodyParts3D, επιστρέφει στον δημόσιο viewer |
| Προεπισκόπηση πρόσθετων 3D μοντέλων | `ui-tools/atla-resource-preview.html` | Προβολή συγκεκριμένων πόρων, όχι ανταγωνιστικός βασικός άτλας |
| ATLAS · Εκπαιδευτικός βοηθός | `atla/assistant.mjs` μέσω `data-atla-open` | Ένα περιβάλλον βοήθειας· ο παλιός MENTOR adapter παραμένει για συμβατότητα |
| Εξάσκηση σε εικονικά περιστατικά | `mentor-next.html` | Ενιαίος υπάρχων προσομοιωτής `tools/patient-simulator/`, όχι κλινικά επικυρωμένος |
| Παλαιότερη εκπαιδευτική αποστολή | `mentor-live.html` | Παλιά λειτουργία άσκησης για παλιούς συνδέσμους, όχι νέα ανεξάρτητη υπηρεσία |
| Εξάσκηση σε ηλεκτροκαρδιογράφημα (ΗΚΓ) | `mentor-ecg.html` | Συνθετικές κυματομορφές, όχι διαγνωστική ερμηνεία |

## Γιατί παραμένουν ιστορικά αρχεία
Το `tools/anatomy-3d/index.html` και το `ui-tools/anatomy-3d/index.html` χρησιμοποιούν την ίδια ενεργή μηχανή. Η ιστορική διαδρομή παραμένει για συμβατότητα και για εργαλεία που τη χρησιμοποιούν. Δεν διαγράφονται δεδομένα ή assets. Η λειτουργία `MENTOR` παραμένει ως παλιός προσαρμογέας, ενώ ο δημόσιος βοηθός φορτώνει μέσω `atla/assistant.mjs`. Το `mentor-live.html` είναι η παλιά εκπαιδευτική αποστολή και το `mentor-next.html` η σημερινή κύρια είσοδος του προσομοιωτή.

## Τι δεν αλλάζει
Καμία αλλαγή σε κώδικα 3D renderer, μοντέλα/άδειες, μεθόδους κλινικής βαθμολόγησης, πηγές, HTTP API, localStorage, μαθησιακή πρόοδο, παλιά URLs, ή υπηρεσίες AI. Δεν μετατρέπουμε προεπισκόπηση σε κλινικά εγκεκριμένο υλικό. Η τελική ονοματοδοσία παραμένει μελλοντική ξεχωριστή απόφαση. Η δοκιμή `scripts/verify-atla-greek-ui.mjs` επιτηρεί τις κοινές διαδρομές.

## Απόφαση 06/11/2026: ATLAS και κατάργηση BioDigital
Η πλατφόρμα διατηρεί το όνομα ATLA, ενώ **ATLAS** είναι το αμετάφραστο όνομα του ενιαίου εκπαιδευτικού βοηθού. Η μη χρησιμοποιούμενη σύνδεση BioDigital αφαιρέθηκε, μαζί με τον αντίστοιχο κώδικα/οθόνη/CI και τη μη εφαρμόσιμη προτεραιότητα παρόχου για εκπαιδευτικό βίντεο. Η αλλαγή δεν επηρεάζει τις υπάρχουσες συλλογές BodyParts3D, NIH 3D, HRA/HuBMAP, τον κύριο ανατομικό viewer, τις εκπαιδευτικές καταγραφές ή τις άδειες των άλλων πηγών. Ο κώδικας BioDigital παραμένει προσβάσιμος στο ιστορικό Git για επαναφορά, αλλά δεν αποτελεί πλέον μέρος του ενεργού έργου.
