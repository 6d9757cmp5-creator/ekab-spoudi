# Αξιολόγηση απαντήσεων με AI — Οδηγός ενεργοποίησης

**Κατάσταση:** Ο κώδικας βρίσκεται στο GitHub, αλλά η υπηρεσία ΔΕΝ είναι ενεργή ώσπου να δημιουργηθεί και να συνδεθεί Appwrite Function. Η εφαρμογή συνεχίζει κανονικά τη χειροκίνητη αυτοαξιολόγηση. Δεν δηλώνουμε ότι υπάρχει ήδη αυτόματη βαθμολόγηση.

## Τι κάνει

- Στα δοκιμαστικά σεμινάρια (BLS/AED, PBLS, ILS, PHTLS, ALS): ερμηνεύει ελεύθερη απάντηση και εμφανίζει σωστή / μερικώς σωστή / λανθασμένη / αβέβαιη. Η πρόοδος σημειώνεται αυτόματα μόνο για σαφές αποτέλεσμα.
- Στη νέα υποενότητα **Κατάρτιση ΣΑΕΚ → Εξετάσεις ΣΑΕΚ**: προαιρετικός έλεγχος της γραπτής απάντησης σε 247 υπάρχοντα εκπαιδευτικά θέματα από τα 20 μαθήματα, χωρίς αλλαγές στην ύλη. Τα κριτήρια διαβάζονται από το server-side `saek-exam-rubrics.json`, όχι από απάντηση χρήστη.
- Στις 314 θεωρητικές ερωτήσεις ΕΟΠΠΕΠ: διαθέσιμο μόνο σε ερωτήσεις με υπάρχουσα **εκπαιδευτική απάντηση** με `answerStatus=reviewed_educational`, όχι στα μη επαληθευμένα προσχέδια.
- Δέχεται ισοδύναμες διατυπώσεις (π.χ. «μαλάξεις στο στήθος» έναντι «θωρακικές συμπιέσεις») και αναγνωρίζει πιθανές επικίνδυνες ελλείψεις.
- Στα αβέβαια δεν καταχωρίζεται αυτόματα επιτυχία. Το μοντέλο μπορεί να κάνει λάθος. **Ούτε το AI ούτε το εκπαιδευτικό υλικό είναι επίσημη βαθμολογία, ιατρική άδεια ή πιστοποίηση.**

## Ενεργοποίηση από Appwrite Console

1. **Έλεγξε κόστος και όρια.** Το Appwrite Free έχει έως 2 Functions ανά project, αλλά η χρήση της OpenAI API χρεώνεται ξεχωριστά, δεν περιλαμβάνεται στη συνδρομή ChatGPT. Δεν έχει ενεργοποιηθεί αυτόματη αναβάθμιση χρέωσης.
2. Στο project `6ade83ec00260198ae34` της περιοχής `fra`: **Functions → Create Function → Connect GitHub** → repository `6d9757cmp5-creator/ekab-spoudi`, branch `main`.
3. Root directory: `functions/answer-grader`. Runtime: **Node.js 22** (ή νεότερο συμβατό), entrypoint: `main.js`. Δεν χρειάζεται npm dependency.
4. Στο **Settings → Execute access** επέτρεψε **μόνο authenticated users** (Role.users()), όχι guests/any/public. Μη δημιουργήσεις public function domain που δέχεται ανώνυμο περιεχόμενο. Μην δώσεις πρόσθετα project API scopes· δεν χρειάζονται.
5. Πρόσθεσε **Function environment variable** `OPENAI_API_KEY` (ιδιωτικά στο Console, ΠΟΤΕ στο GitHub), προαιρετικά `OPENAI_MODEL=gpt-4o-mini`. Μετά κάνε deployment / redeployment. Μην χρησιμοποιείς το προσωπικό ChatGPT token.
6. Αντέγραψε το **Function ID** (δημόσιο αναγνωριστικό, όχι secret) στο `ai-grading-config.js` ως `functionId:'<το πραγματικό id>'`. Δημοσίευσε τον αλλαγμένο κώδικα. Η ενεργοποίηση πρέπει να γίνει **μόνο μετά** από επιτυχές δοκιμαστικό execution.
7. Δοκίμασε από Google login: παραφρασμένη σωστή απάντηση, ελλιπή απάντηση, επικίνδυνο λάθος, κενή απάντηση, μη συνδεδεμένο χρήστη, offline λειτουργία, υπέρβαση ορίου, διαφορετική ερώτηση ενόσω τρέχει το αίτημα. Έλεγξε ότι η παλιά πρόοδος δεν αντικαθίσταται.

**Προσοχή:** Τα αποτελέσματα είναι ποιοτική εκτίμηση, όχι αξιόπιστη επίσημη βαθμολόγηση. Η βιβλιογραφία μπορεί να περιέχει εκκρεμότητες. Χρειάζεται κλινική επιμέλεια rubric προτού χρησιμοποιηθεί για αποφάσεις υψηλού κινδύνου.

## Προστασία προσωπικών δεδομένων και λειτουργικά όρια

- Απαιτείται ενεργός Appwrite λογαριασμός και ρητό πάτημα «Αξιολόγηση με AI». Μόνο τότε στέλνεται η συγκεκριμένη γραπτή απάντηση (μέγιστο 3500 χαρακτήρες) στον διακομιστή και τον πάροχο μοντέλου. **Να μην εισάγονται ονόματα ασθενών ή αναγνωριστικά ιατρικά δεδομένα.**
- Δεν στέλνονται ολόκληρο ιστορικό, προσωπικά PDF, υπόλοιπη πρόοδος ή διαπιστευτήρια στον πάροχο μοντέλου. Εφαρμόζεται `store:false` στην OpenAI Responses API. Λάβε υπόψη την πολιτική επεξεργασίας δεδομένων των εμπλεκομένων παρόχων και τα αρχεία/μεταδεδομένα εκτελέσεων του Appwrite.
- Ο κώδικας backend διαβάζει τα κριτήρια από project-controlled αρχεία αντί να εμπιστεύεται «σωστή λύση» που του στέλνει ο χρήστης. Δεν αποθηκεύει ο ίδιος τις υποβολές. Μην ενεργοποιείς debug logs που περιέχουν σώματα αιτημάτων ή αποκρίσεις.
- Έχει απλό προσωρινό όριο έως 15 αιτήσεις / 20 λεπτά ανά user **ανά λειτουργούσα διεργασία**. Δεν αποτελεί ασφαλές γενικό ημερήσιο όριο χρέωσης ή εξασφάλιση έναντι abuse σε πολλαπλά instances. Πριν το δημόσιο rollout βάλε κεντρικό quota/budget alert στον provider, account-based rate limiting και δοκίμασε τα πραγματικά όρια.
- Η αυτόματη κρίση ενημερώνει την πρόοδο μόνο εφόσον υπάρχει μη αβέβαιη αξιολόγηση και ο μαθητής δεν έχει ήδη δει την ενδεικτική λύση στον ΕΟΠΠΕΠ. Σε αμφιβολία μένει δυνατή η προσωπική αξιολόγηση.
- Σε αστοχία διακομιστή, έλλειψη config, offline ή μη συνδεδεμένο χρήστη: εμφανίζεται έντιμο μήνυμα και ο χρήστης χρησιμοποιεί τη χειροκίνητη αυτοαξιολόγηση. Δεν υπάρχει ψευδής «αυτόματη βαθμολογία».

## Αρχιτεκτονική

GitHub Pages (στατικό frontend) → Appwrite Web client, authenticated `POST /functions/{id}/executions` → Appwrite Function Node 22 `functions/answer-grader/main.js` → OpenAI Responses API, structured JSON schema → παρουσίαση/ενδεχόμενη καταχώριση προόδου τοπικά.

Η συνάρτηση χρησιμοποιεί σταθερά project-controlled rubrics (`seminar-rubrics.json`, `saek-exam-rubrics.json`) και τη δημόσια τράπεζα ΕΟΠΠΕΠ από το συγκεκριμένο repository. Τα δεδομένα ΕΟΠΠΕΠ δεν παρουσιάζονται ως επίσημο λυσάρι.
