# Ασφαλής ενσωμάτωση ευρημάτων Claude (PR #140)

Ο εισαγωγέας `merge-claude-eoppep.cjs` εισάγει την **πλήρη τεκμηρίωση Claude** σε `eoppep-314.json > entries[].externalReviews`, διατηρώντας ανέπαφα τα υπάρχοντα `question`, `answerCharacters`, `targetedReview`, `fullAnswerReview`, `resolution`, `status` και κάθε άλλη αρχική ιδιότητα. **Δεν αλλάζει παραγωγικές απαντήσεις, δεν συγχωνεύει PR, δεν εκδίδει κλινική πιστοποίηση.**

## Εκτέλεση

Από τη ρίζα του αποθετηρίου, στο branch `audit/claude-eoppep-b-crosscheck-20261031`:

```bash
node --test docs/primary-source-crosscheck-2026-10-28/merge-claude-eoppep.test.cjs
node docs/primary-source-crosscheck-2026-10-28/merge-claude-eoppep.cjs
```

Ο προκαταρκτικός έλεγχος είναι read-only. Το `--apply` επιτρέπεται **μόνο** στο παραπάνω branch και γράφει μόνο το κοινό μητρώο. Δεύτερη εισαγωγή ίδιου περιεχομένου δεν αλλάζει τίποτα. Αν το Claude αλλάξει ήδη εισαγμένο εύρημα του ίδιου ID, η λειτουργία αποτυγχάνει με σαφή σύγκρουση για **χειροκίνητη συμφιλίωση**. Διατηρεί τυχόν άλλες ανεξάρτητες αξιολογήσεις.

## Κανόνες ποιότητας

- Ελέγχει τα 314 μοναδικά canonical IDs (105 Α + 209 Β), τα IDs ευρημάτων, τα υποχρεωτικά πεδία, τις πηγές HTTPS, τα verdicts και τις ημερομηνίες.
- Καταγράφει όλα τα ευρήματα με ακριβές ID και **ολόκληρο το evidence record**, χωρίς να αλλάζει την αρχική ερώτηση.
- `canonicalQuestionExactMatch:false` σημαίνει ότι ο Claude συνόψισε ή παρέφρασε την εκφώνηση· απαιτείται προσεκτική επιβεβαίωση ταύτισης.
- `SOURCE_UNVERIFIED` σημαίνει ότι η πηγή δεν ήταν προσβάσιμη. Η εγγραφή **δεν** λογίζεται ως τεκμηριωμένος έλεγχος.
- `AI_DOCUMENTARY_REVIEW_PENDING_SIGNOFF` σημαίνει στοχευμένη βοήθεια AI, **όχι** ανθρώπινη κλινική έγκριση. Ο αρχικός μετρητής `targetedReview` δεν αλλάζει.
- Οι ήδη ελεγμένες εγγραφές αποκτούν μόνο συμπληρωματική παραπομπή `externalReviews` — δεν διπλομετρώνται.
- `fullScientificApproval:false`, `humanClinicalSignoff:false` ακόμη και για `consistent`. Για φάρμακα, ALS, αεραγωγό κ.λπ. απαιτείται έλεγχος από αρμόδιο κλινικό πριν από εφαρμογή.
- Οι μελλοντικές αλλαγές σε νέο branch του Claude πρέπει να συγκρίνονται με το πιο πρόσφατο κοινό μητρώο του PR #39. Η συγχώνευση PR #140 στο #39, αν εγκριθεί, να γίνει μόνο μετά από έλεγχο συγκρούσεων και μετρήσεων. **Όχι αυτόματο merge.**

**Απολογισμός στο αρχικό δείγμα:** 29 μοναδικά ευρήματα Claude = 24 IDs χωρίς προηγούμενο targetedReview + 5 ήδη ελεγμένα. Από τα 24, 3 έχουν μη προσβάσιμες πηγές και παραμένουν ανοικτά. Ο αριθμός 310/561 του κύριου PR **δεν αυξάνεται** μόνο με την εισαγωγή εξωτερικής τεκμηρίωσης. Οποιαδήποτε προαγωγή από externalReview σε targetedReview απαιτεί ανεξάρτητο έλεγχο του περιεχομένου και τεκμηριωμένη απόφαση.
