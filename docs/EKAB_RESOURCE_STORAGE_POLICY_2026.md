# ΕΚΑΒ Σπουδή — πολιτική αποθήκευσης και ανάκτησης (03/11/2026)

## Τρέχουσα κύρια λειτουργία

Η ενεργή NIH 3D υπηρεσία (`.github/workflows/atla-nih3d-direct-source.yml`) χρησιμοποιεί επίσημους συνδέσμους πρωτότυπων αρχείων κατόπιν ζήτησης αντί να αντιγράφει όλο το υλικό στο GitHub. Οι σύνδεσμοι **δεν αποτελούν μόνιμο αντίγραφο** των αρχείων. Ο παλιός αυτοματισμός μαζικής δημοσίευσης NIH 3D αφαιρέθηκε από το main πριν από αυτή την αλλαγή. Δεν επανενεργοποιείται.

Τα νέα GitHub Actions artifacts χρησιμοποιούνται μόνο όταν πραγματικά χρειάζονται για ενδιάμεσα στάδια, στοιχεία ελέγχου ή ανάκτηση. Δεν υποκαθιστούν μόνιμη βιβλιοθήκη. Αρχεία που είναι ήδη στον κώδικα δεν χρειάζονται δεύτερη μόνιμη αντιγραφή.

## Ανάκτηση ιστορικών προσωρινών πακέτων NIH 3D

Το νέο `.github/workflows/recover-nih3d-artifacts.yml` εκτελεί ασφαλή ανάκτηση μόνο των **παλαιών fallback** artifacts με μορφή `nih3d-originals-<start>`, εφόσον λείπει το αντίστοιχο canonical RESULT.json από το υπάρχον Release `atla-nih3d-master-2026`. Πρόκειται για μηχανισμό ανάκτησης παλαιού υλικού και **όχι** νέο μαζικό downloader.

- Προγραμματισμένη εκτέλεση 4 φορές ημερησίως και χειροκίνητη εκκίνηση.
- Μέχρι 2 πακέτα ανά εκτέλεση, προτεραιότητα στην ημερομηνία λήξης.
- Όλα τα τμήματα και το RESULT.json επαληθεύονται τοπικά· το manifest μεταφορτώνεται τελευταίο.
- Υπάρχοντα Release assets δεν αντικαθίστανται ποτέ. Αν διαφέρουν μέγεθος ή digest η διαδικασία αποτυγχάνει.
- Τα πρωτότυπα artifacts **δεν διαγράφονται**.
- Αρχεία άνω των 6 GiB δεν ανακτώνται στον συνήθη runner και αναφέρονται ως ξεχωριστό εμπόδιο.
- Υλικό άλλων οικογενειών (περιορισμένης χρήσης ερευνητικά αρχεία, test reports, βιβλία, BodyParts3D) δεν μεταφέρεται αυτόματα σε δημόσιο Release. Μπορεί ήδη να είναι αποθηκευμένο στον κώδικα ή να απαιτεί άλλη πολιτική.

Η δημοσίευση ενός αρχείου στο Release δεν αποδεικνύει επιστημονική εγκυρότητα ή ενεργοποίηση στο εκπαιδευτικό περιβάλλον. Τα μεταδεδομένα πηγής και άδειας παραμένουν στο RESULT.json.

**Όριο:** Δεν έχει επιβεβαιωθεί ότι και τα 19 artifacts των 304,47 GB ανήκουν σε αυτή την οικογένεια. Η ύπαρξη του αυτοματισμού δεν ισοδυναμεί με ολοκλήρωση μεταφοράς. Ελέγχουμε τα Actions runs, την απογραφή των πραγματικών assets και την ημερομηνία λήξης προτού δηλώσουμε ασφάλεια.
