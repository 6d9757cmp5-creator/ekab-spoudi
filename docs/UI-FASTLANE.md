# ΕΚΑΒ Σπουδή — γρήγορη δημοσίευση εργαλείων και interface

## Πολιτική
Οι αλλαγές μόνο σε εργαλεία, εμφάνιση, πλοήγηση και προσβασιμότητα επιδιώκεται να μπαίνουν αυτόματα στην εφαρμογή, μόλις ολοκληρωθούν με επιτυχία οι τεχνικοί έλεγχοι. Δεν απαιτείται χειροκίνητη έγκριση για τις ρητά επιτρεπόμενες αλλαγές.

**Δεν ισχύει για** εκπαιδευτική ύλη, ορισμούς ιατρικών οδηγιών, ερωτήσεις/απαντήσεις, δοσολογίες, βαθμολογική λογική, εικόνες, ήχο, βίντεο, PDF, ρυθμίσεις ασφάλειας ή συγχρονισμό προσωπικής προόδου.

## Υλοποίηση
- Το `.github/workflows/ui-fastlane.yml` ελέγχει αυτόματα Pull Requests στο `main`. Εσωτερικά παραμένει PR για να τηρείται ο υφιστάμενος κανόνας του GitHub, αλλά δεν απαιτείται χειροκίνητο merge στις επιλέξιμες αλλαγές.
- Τα τροποποιημένα αρχεία πρέπει να περιορίζονται στον συντηρητικό κατάλογο UI του workflow ή στους φακέλους `ui-tools/` και `ui-components/`. Μικτό PR απορρίπτεται από το fastlane, **όχι** από το GitHub· εξετάζεται χειροκίνητα.
- Απαιτείται επιτυχία `media-gate` και `release-smoke` στο ίδιο commit, επιτυχημένος έλεγχος σύνταξης JavaScript και κατάσταση συγχώνευσης `clean`. Σε απουσία ελέγχων, σύγκρουση ή αμφιβολία το fastlane **δεν δημοσιεύει**.
- Επιτρέπονται μόνο αλλαγές από branches του ίδιου αποθετηρίου που δημιουργούνται από τον ιδιοκτήτη. Δεν εκτελείται ο κώδικας του PR μέσα σε προνομιούχο περιβάλλον.
- Μετά τη συγχώνευση ζητείται νέο GitHub Pages build, εφόσον η τρέχουσα ρύθμιση Pages το υποστηρίζει. Το live deployment πρέπει να επιβεβαιώνεται ξεχωριστά.

## Αρχική ενεργοποίηση / όρια
Το workflow **δεν είναι ενεργό μέχρι να συγχωνευτεί στο `main`** με την υφιστάμενη προστασία. Η σύνδεση GitHub που χρησιμοποιείται στη συνομιλία δεν υποστηρίζει αλλαγή του GitHub ruleset ή των repository settings. Η απαιτούμενη πολιτική PR παραμένει, αλλά η διαδικασία γίνεται αυτόματη στο παρασκήνιο για τα ασφαλή UI-only changes.

Το auto-merge δεν αποτελεί επιστημονική έγκριση, ούτε αντικαθιστά δοκιμές σε κινητό, browser και offline.
