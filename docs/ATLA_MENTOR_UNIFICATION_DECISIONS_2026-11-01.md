> **Ενημέρωση 01/11/2026:** Ο τελικός προηγμένος AI βοηθός ονομάζεται **ATLAS** (διάδοχος MENTOR AI). Το **AI Αξιολόγησης Απαντήσεων** παραμένει αυστηρά ξεχωριστός evaluator που συγκρίνει τη γραπτή απάντηση μαθητή με τα κριτήρια του συστήματος. Το ATLAS μπορεί να χρησιμοποιεί την *έτοιμη* αξιολόγηση για διδασκαλία, αλλά δεν δημιουργεί δεύτερη βαθμολογία. Η εικονική συνομιλία ενεργοποιείται ρητά ως **DEMO** με σήμανση σε κάθε απάντηση και ποτέ δεν καλεί το grader ή το πραγματικό μοντέλο. Βλ. [συγκεκριμένη προδιαγραφή](ATLAS_AI_GRADING_AND_MOCK_ARCHITECTURE_2026-11-01.md).

# ΕΚΑΒ Σπουδή — Ενιαίο σχέδιο ATLA / απορρόφηση MENTOR OS

**Απόφαση προϊόντος: 01/11/2026.** **Κατάσταση:** εγκεκριμένη κατεύθυνση και αποτύπωση, **όχι ολοκληρωμένη υλοποίηση**. Το `main`, οι παραγωγικές οθόνες και τα δεδομένα προόδου δεν αλλάζουν από αυτό το έγγραφο.

## 1. Τελικός στόχος και ονομασία

- Ένα εκπαιδευτικό προϊόν: **ΕΚΑΒ Σπουδή**. Ένας οριζόντιος AI καθηγητής/βοηθός: **ATLA**. Το «ATLAS» μπορεί να χρησιμοποιηθεί ως ονομασία του ενοποιημένου τεχνολογικού συστήματος ΜΟΝΟ αν επιλεγεί ως μία ενιαία ονομασία, όχι δεύτερος AI agent.
- Μετά την πλήρη μετεγκατάσταση **δεν υπάρχει ενεργός MENTOR OS**, δεύτερη συνομιλία, αυτόνομο MENTOR Lab / 3D avatar ή ανεξάρτητη εφαρμογή MENTOR, ούτε ενεργός ιδιοκτήτης κώδικα `mentor/` ή `tools/mentor-os/`.
- Ό,τι χρήσιμο υπάρχει στον σημερινό MENTOR μεταφέρεται/ενοποιείται με ATLA ή το αντίστοιχο εξειδικευμένο εργαλείο. Κατάργηση παλαιού namespace και ονομάτων μόνο μετά από αποτύπωση dependencies, μεταφορά, migration tests, browser QA και rollback readiness.
- Η ιστορία των παλιών commits δεν επανεγγράφεται. Τα παλαιά `mentor-*.html` URL μπορούν προσωρινά να λειτουργούν ως **ελάχιστες γέφυρες** χωρίς ενεργό MENTOR OS, επειδή η GitHub Pages δεν παρέχει καθολικά αυτόματο server-side redirect. Μετά το migration και τον έλεγχο bookmarks αποφασίζεται η τελική απομάκρυνσή τους, με σαφή γνώση ότι τα παλαιά URLs τότε ίσως πάψουν να λειτουργούν.

## 2. Σχεδιαστική γραμμή (Beta 0.1–0.4)

- Διατηρούμε την επιτυχημένη desktop ταυτότητα (μπλε/πετρόλ, πλαϊνή πλοήγηση, καθαρές κάρτες) και τη βελτιωμένη κινητή έκδοση (σύντομη αρχική, ευανάγνωστα μαθήματα, σταθερή κάτω πλοήγηση, ATLA προσβάσιμη από παντού).
- Η ATLA δεν περιορίζεται στη μελέτη: είναι AI καθηγήτρια **και** AI βοηθός όλης της εφαρμογής. Διακριτικό παράθυρο/side panel, χωρίς μόνιμο επιβλητικό avatar ή ολογράμματα.
- Οι βασικές διαδρομές είναι: **ΣΑΕΚ**, **ΕΟΠΠΕΠ** (η ιστορική πρακτική εξέταση είναι τμήμα της ενότητας ΕΟΠΠΕΠ), **Clinical Cockpit** και **Βιβλιοθήκη**. Φαρμακολογία, δίγλωσσο ιατρικό λεξικό, Anatomy Lab, πρωτόκολλα, σεμινάρια, ECG Lab, νομοθεσία, προσωπικά PDF, σημειώσεις/αναζήτηση παραμένουν προσβάσιμα και χρήσιμα.
- Παιδαγωγική ροή: ενεργητική μελέτη → ανάκληση → εφαρμογή → ανασκόπηση στην ίδια ενότητα → στοχευμένη επανάληψη. Αποφυγή περιττών οθονών, όχι απομάκρυνση εκπαιδευτικού περιεχομένου.
- Η φιλοδοξία διεθνούς/ερευνητικής διάκρισης είναι **στόχος ποιότητας**, όχι ισχυρισμός βράβευσης, επιστημονικής επικύρωσης ή πανεπιστημιακής έγκρισης.

## 3. Χάρτης μετεγκατάστασης από MENTOR

| --- | --- | --- |
| `mentor/app/adaptive.js`, `mentor/intelligence/next-step.mjs`, προγράμματα/στόχοι μελέτης | `atla/learning/` + κοινός scheduler | Ενοποίηση προσωποποιημένου καθηγητή, εξήγησης ανά επίπεδο, επανάληψης και συστάσεων, χωρίς δεύτερο score |
| `mentor/presence/`, `mentor/context/`, `mentor-study-bridge.mjs` | `atla/assistant/` + `services/context/` | Μία ATLA σε όλες τις οθόνες, ανάγνωση εκπαιδευτικού context με συγκατάθεση, ασφαλής επιστροφή στο ίδιο κεφάλαιο |
| `mentor/knowledge/retrieve.mjs`, quick-answer, `mentor/ai/`, `workers/mentor-chat/` | `atla/knowledge/`, `atla/ai/`, κοινή retrieval υπηρεσία | Αναβάθμιση από τοπικούς όρους/κανόνες σε ενιαία αξιόπιστη ανάκτηση της ΣΑΕΚ, ΕΟΠΠΕΠ και Βιβλιοθήκης. Η πραγματική AI σύνδεση δεν θεωρείται ενεργή μέχρι να δοκιμαστεί και να ενεργοποιηθεί |
| `mentor/presence/memory.mjs`, personal-v1, readonly progress, study-goals | `services/learner-profile/` + `atla/learning/` | Ένα προφίλ μαθητή, μία καταγραφή προόδου ανά γεγονός/πηγή, ξεχωριστά αρχικά δεδομένα σε migration χωρίς απώλειες |
| `mentor/voice/`, `mentor/presence/voice.mjs` | `atla/voice/` | Προαιρετική ελληνική φωνή/μικρόφωνο, όχι υποχρεωτικό 3D παρουσιαστικό |

| `mentor/app/live.js`, activity engine, missions, MCI/equipment, `mentor-next.html` | `tools/patient-simulator/` / Clinical Cockpit | Ενιαίος προσομοιωτής, όχι δεύτερη προσομοίωση ATLA· ATLA παρέχει καθοδήγηση και ανασκόπηση |
| `mentor/scenario-atlas/`, scenarios | `tools/scenario-library/` + Clinical Cockpit | Ένας κατάλογος περιστατικών, σενάρια αναγνωρισμένα ως demo/outline έως επιστημονική επιμέλεια |
| `mentor/app/ecg.js`, `mentor-ecg.html` | `tools/ecg-lab/` | Κρατάμε τις εξειδικευμένες λειτουργίες στο ECG Lab, με ATLA ως εκπαιδευτικό βοηθό |
| `mentor/app/oral.js`, oral practice | ΕΟΠΠΕΠ/κοινή υπηρεσία εξετάσεων όπου αρμόζει | Προφορική εξάσκηση, διόρθωση/επεξήγηση χωρίς δεύτερο βαθμολογικό μηχανισμό |
| `mentor/app/library.js`, read-only, glossary | `services/search/` + Βιβλιοθήκη + ATLA | Μία αναζήτηση/μία γνώση, χωρίς δεύτερο λεξικό |
| `mentor/avatar/`, `mentor/real-avatar/`, `mentor/assets/`, 3D cinematic/presence UI | Αποεπιλογή από την ATLA. Επαναχρησιμοποίηση μόνο εάν υπάρχει πραγματική ανάγκη στα ειδικά 3D εργαλεία | Δεν διατηρούμε τον 3D MENTOR ως τμήμα της κοινής διεπαφής. **Η ATLA δεν γίνεται ιδιοκτήτρια της φυσιολογίας του ασθενούς, του 3D anatomy renderer, των ερωτήσεων ΕΟΠΠΕΠ ή των επίσημων αποτελεσμάτων.** Συντονίζει εκπαιδευτικά τους ειδικούς engines, δεν τους αντιγράφει.

## 4. Αμφίδρομη συνεργασία χωρίς διπλασιασμό

Παράδειγμα: κεφάλαιο ΣΑΕΚ → συγκεκριμένο ανατομικό αντικείμενο στο **ATLA Anatomy Lab** → περίπτωση στο **ATLA Clinical Cockpit** → ανασκόπηση στην ίδια περίπτωση → εξατομικευμένη εξήγηση ATLA → στοχευμένο κεφάλαιο/ερώτηση ΕΟΠΠΕΠ → επιστροφή ακριβώς στο προηγούμενο context.

- Ένα εκπαιδευτικό event schema (`learnerId` όπου επιτρέπεται, `toolId`, `contentId`, `attemptId`, `eventType`, `timestamp`, `outcome`, version) και μία κοινή υπηρεσία σύνοψης. Τα υπάρχοντα schemas δεν καταργούνται πριν από δοκιμασμένη μετεγκατάσταση.
- Διακριτά tool modules: `tools/anatomy-3d/`, `tools/patient-simulator/`, `tools/ecg-lab/`, `tools/pharmacology/`, `tools/seminars/` και άλλα. Κοινά: search, learner profile, scheduler, feedback, sync, context, ATLA.
- Μία canonical βαθμολογία ανά τύπο δοκιμασίας, όχι αντιγραφή ή τεχνητή συγχώνευση των παλιών scores. Διαχωρισμός «μελετήθηκε», «εξετάστηκε», «ολοκληρώθηκε σενάριο» και «εκκρεμεί επανάληψη».
- Σε ενεργή εξεταστική λειτουργία η ATLA δεν υποδεικνύει τις απαντήσεις. Μετά το τέλος επιτρέπεται επεξήγηση.
- Η ATLA δεν αποκτά αυθαίρετη πρόσβαση σε προσωπικές σημειώσεις, ιστορικά δεδομένα, διαγνωστικά ή περιεχόμενο συνομιλιών. Ο μαθητής ενημερώνεται και ελέγχει τις επιλογές συγκατάθεσης, διαγραφής και συγχρονισμού.

## 5. Διαδοχικές φάσεις GitHub

1. **Audit:** πλήρης κατάλογος `mentor/`, `mentor-*.html/js/css`, worker, `tools/mentor-os/`, test fixtures, storage keys, root imports, εξαρτήσεων και HTML deep links. Freeze/backup της τρέχουσας βάσης και έλεγχος σύγκρουσης branches.
2. **Νέος ένας πυρήνας `atla/`:** AI adapter + retrieval, κοινό context, διακριτική παρουσία, προφορική διεπαφή, adaptive logic, ενιαίος εκπαιδευτικός βοηθός. Πρώτα δοκιμή χωρίς αλλαγή βαθμολογίας.
3. **Μετεγκατάσταση ειδικών λειτουργιών:** Clinical Cockpit, ECG, σενάρια, ανασκόπηση in-place, προφορικά, Βιβλιοθήκη. Μη δημιουργηθεί δεύτερος κώδικας κανονικής λειτουργίας· μόνο προσωρινά adapters.
4. **Ένα προφίλ και μία ιστορία μάθησης:** schema, idempotent migration από όλα τα υπάρχοντα storage keys/IndexedDB, backup/restore, cloud-sync consistency, smoke με παλιά πραγματικά δείγματα.
5. **UI Beta → production:** κρατάμε desktop visual baseline Beta 0.1–0.4, mobile bottom navigation, ακριβή anchors και αποφυγή overlay, έλεγχο προσβασιμότητας.
6. **Καθαρισμός MENTOR namespace:** αφαιρούμε UI, active imports, `mentor/` και `tools/mentor-os/` μόνο όταν καμία runtime εξάρτηση/δοκιμή/αναφορά δεν τα απαιτεί. Μεταφέρουμε εργαλεία και ενημερώνουμε registry, CI, docs και public URLs/redirect stubs.
7. **QA και τελική παραλαβή:** unit, integration, browser journeys, 320/390/768/1440 px, πραγματικό iPhone Safari, Android, desktop, offline/online, accessibility, data migration, sync, backup, rollbacks, επιστημονική ακρίβεια και πραγματική εκπαιδευτική επίδοση.

## 6. Κριτήρια ότι «δεν έχει μείνει MENTOR»

- Μία και μοναδική ATLA στο UI και στα public labels.
- Καμία ενεργή `mentor/` ή `tools/mentor-os/` βάση λειτουργιών, κανένα `mentor` import που παράγει τον καθηγητή.
- Καμία ξεχωριστή σελίδα DEBRIEF ως εργαλείο, αλλά όλες οι ανασκοπήσεις εξακολουθούν να λειτουργούν in-place.
- Κανένα διπλό learner profile, scheduler, quiz grade, memory ή επιστημονικό catalog.
- Καμία απώλεια αποθηκευμένης επίδοσης ή διαδρομής, έλεγχος παλιών bookmarks και deep links.
- Εργαλειακή ανεξαρτησία Anatomy Lab/Clinical Cockpit, κοινή ATLA.
- Ονόματα/registry/README/tests/release scripts ενημερωμένα. Η τελική δημόσια ονομασία ATLA ή ATLAS παραμένει **μία**, όχι δύο ανταγωνιστικές προσωπικότητες.

**Σημαντική τρέχουσα πραγματικότητα:** Η σημερινή AI configuration `mentor/ai/config.mjs` έχει κενό endpoint, άρα δεν παρουσιάζουμε την ATLA ως ήδη συνδεδεμένη σε πλήρη παραγωγικό AI. Η νέα διεπαφή Beta 0.4 είναι πρωτότυπο και δεν ισοδυναμεί με ενεργή ενοποίηση.
