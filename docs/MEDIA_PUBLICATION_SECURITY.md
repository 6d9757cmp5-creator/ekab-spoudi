# ΕΚΑΒ Σπουδή — Ασφαλής δημοσίευση εκπαιδευτικών μέσων

## Κατάσταση
Το `media-gate` ελέγχει τις αλλαγές στο repository. **Δεν επιβάλλει από μόνο του branch protection**, ούτε σαρώνει ανεξάρτητα το ιατρικό περιεχόμενο. Η εκπαιδευτική επαλήθευση βασίζεται σε πλήρη πρωτογενή τεκμήρια, δεύτερο ανεξάρτητο AI/source-review και τη δεσμευτική [πολιτική τεκμηρίωσης](ATLA_AI_EVIDENCE_RELEASE_RULE_2026-11-04.md). Δεν ισοδυναμεί με κλινική πιστοποίηση.

## Υποχρεωτικές ρυθμίσεις GitHub
Repository Settings → Rules → Rulesets → New branch ruleset:
- Name: `main-production-gate`, target `main`, Enforcement: Active.
- Require pull request, τα πραγματικά απαιτούμενα status checks και επίλυση συζητήσεων. Κριτήρια αξιολόγησης περιεχομένου βασισμένα σε τεκμήρια, όχι καθολική κλινική υπογραφή.
- Require status check **`media-gate`** από GitHub Actions.
- Block force pushes/deletions. No routine bypass.
- Ενεργοποίηση πρόσθετων GitHub approvals/branch rules μόνο εφόσον έχουν ελεγχθεί οι πραγματικές διαθέσιμες άδειες και δεν κλειδώνουν ακούσια το repository. Η παρούσα πολιτική δεν τροποποιεί live GitHub ruleset.
- Επιβεβαίωση: ένα PR με ανεπαρκώς τεκμηριωμένο νέο media **δεν** μπορεί να συγχωνευθεί, ενώ η στατική δοκιμή ξεχωρίζει την ακεραιότητα από την επιστημονική αντιπαραβολή.

## Appwrite — ξεχωριστή υποδομή, όχι αλλαγές στο private sync
- Το υφιστάμενο private sync και τα προσωπικά PDF **δεν τροποποιούνται**.
- Δημιουργία ξεχωριστού private quarantine bucket και public bucket με **server-only write**.
- Upload ≠ publish. Απαιτούνται έλεγχος πραγματικού format, SHA-256, malware scan, άδεια χρήσης, αντιστοίχιση μαθήματος, ελληνική λεζάντα, επιστημονικές εγκρίσεις.
- Τα αρχεία >20 MB χρειάζονται ανεξάρτητο scanner: το ενσωματωμένο antivirus της Appwrite δεν αρκεί.
- Το μητρώο επιστημονικής/εκπαιδευτικής αντιπαραβολής δένεται στο ακριβές SHA-256, με audit log, σαφή κατάσταση πηγών και δυνατότητα ανάκλησης. Έλεγχος hash ξανά αμέσως πριν τη δημοσίευση.
- Απαιτούνται Appwrite Console admin, Functions, ασφαλή server secrets και δοκιμές δικαιωμάτων. **Δεν είναι ενεργό μέχρι να επαληθευτεί στον server.**

## Επιστημονικός έλεγχος
- Η δεύτερη ανεξάρτητη αντιπαραβολή AI/Deep Research εξετάζει πραγματικές πρωτογενείς πηγές, αντιφάσεις, περιορισμούς και τα ακριβή αρχεία. Απλό AI PASS χωρίς αναγνώσιμες πηγές, έκδοση, σελίδα και διορθώσεις δεν αποτελεί έγκριση.
- Για υλικό υψηλού κινδύνου (ΚΑΡΠΑ, αεραγωγός, φάρμακα, αλγόριθμοι) απαιτούνται δύο ανεξάρτητες **διαδρομές αξιολόγησης πηγών**, καταγεγραμμένο red-team, έλεγχος πεδίου πράξεων και μηδέν ανεπίλυτα P0/P1. Μη επαληθευμένα SOP δεν παρουσιάζονται ως ισχύοντα.
- Καμία αυτόματη έγκριση εικόνων του PR #6 χωρίς έλεγχο ακρίβειας, πηγών, δικαιωμάτων και αντιστοίχισης με μάθημα.

## Σειρά ενεργοποίησης
1. Επαλήθευση πραγματικού περιεχομένου/πηγών με δύο ανεξάρτητες AI διαδρομές, CI και browser QA.
2. Ruleset και επαλήθευση αποκλεισμού μη εγκεκριμένου PR.
3. Appwrite staging quarantine/scanner/approval/publisher.
4. End-to-end αρνητικές και θετικές δοκιμές.
5. Παραγωγή και επανέλεγχος, χωρίς διακοπή private sync.
