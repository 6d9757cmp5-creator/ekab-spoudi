# ΕΚΑΒ Σπουδή v27.1 — Στοχευμένες διορθώσεις

**25/10/2026** · Διορθώθηκαν μόνο τα παρακάτω μαθήματα/κεφάλαια. Διατηρήθηκαν όλα τα IDs προόδου, οι 314 ερωτήσεις ΕΟΠΠΕΠ και η αποθήκευση.

- **01/13**: συμπλήρωση βασικής ανατομίας αναπαραγωγικού.
- **05/07**: ρητή προτεραιότητα καταστροφικής αιμορραγίας στο τραύμα (X-ABCDE).
- **06/08**: αντικατάσταση επαναλαμβανόμενης ερώτησης Αγγλικών.
- **10/12**: ενδομυϊκή αδρεναλίνη πρώτης γραμμής στην αναφυλαξία, χωρίς αυτόματη φαρμακευτική εξουσιοδότηση.

- **12/03**: διάκριση θεωρητικής φαρμακολογίας και ελληνικών επαγγελματικών αρμοδιοτήτων.
- **14/07, 18/09**: αναγνώριση επικίνδυνου θωρακικού τραύματος, χωρίς ανεξέλεγκτους επεμβατικούς χειρισμούς.

- **17/08**: κλινική εκτίμηση μετά από επιτυχή κοιλιακές ωθήσεις/θωρακικές συμπιέσεις.
