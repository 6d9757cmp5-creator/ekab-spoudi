# ΕΚΑΒ Σπουδή — δεύτερο AI ελέγχου βίντεο

**Κατάσταση:** Κώδικας έτοιμος στον κλάδο του PR. Η πραγματική χρήση απαιτεί μυστικό GitHub Actions `OPENAI_API_KEY`, εξαγόμενο MP4 και επιστημονικά ελεγμένες αναφορές. **Καμία από τις 30 παλιές εγγραφές Scrimba δεν έχει εγκριθεί από αυτή τη διαδικασία.**

## Τι κάνει το δεύτερο AI

Το πρώτο AI (Explain/Scrimba) δημιουργεί τη βιντεοδιδασκαλία. Ένα **άλλο σύστημα, με OpenAI API**, αναλύει **το πραγματικό εξαγόμενο αρχείο MP4**, χωρίς να θεωρεί σωστή την έξοδο του πρώτου AI.

* Ελέγχει τη **συνολική απομαγνητοφώνηση** και τη συγκρίνει με χωριστά ελεγμένη, τεκμηριωμένη ύλη.
* Διαβάζει εικόνες του βίντεο **ανά 10 δευτερόλεπτα** (όχι κάθε μεμονωμένο καρέ), συγκρίνει ελληνικές επιγραφές, ανατομία, θέσεις οργάνων, κινήσεις και συγχρονισμό με κοντινό λόγο.
* Ελέγχει **πληρότητα, ακρίβεια, ασφαλή κλινικά όρια, απλή διδακτική εξήγηση, παραδείγματα και διδακτική δομή**.
* Παράγει έκθεση JSON με σκορ, σοβαρότητα, χρονική ένδειξη και προτεινόμενη διόρθωση. Δεν δημοσιεύει από μόνο του τίποτα.

Απόρριψη αν σκορ κάτω από **90/100**, αν οποιοσδήποτε επιμέρους έλεγχος κάτω από **90/100**, αν υπάρχει κρίσιμο/σοβαρό σφάλμα, έλλειψη τεκμηρίωσης, αδυναμία ανάγνωσης MP4/ήχου/καρέ ή έλλειψη API key. Ακόμα και όταν το AI εισηγείται έγκριση, χρειάζεται **υπογραφή υπεύθυνου + κατάλληλου κλινικού ελεγκτή**. Το AI δεν πιστοποιεί από μόνο του ιατρική ασφάλεια.

## Διαδικασία για ένα νέο βίντεο

1. Από το Explain/Scrimba **εξαγωγή MP4** από το ίδιο τελικό βίντεο που θα αναρτηθεί. Ο σύνδεσμος Scrimba **δεν είναι** το ίδιο το MP4. Αν το εξαγόμενο βίντεο αλλάξει, απαιτείται νέος έλεγχος.
2. Δημιουργία αναφοράς `video-reviews/references/01-01.md` για το κεφάλαιο 01 του μαθήματος 01, με **τουλάχιστον 350 χαρακτήρες, συγκεκριμένη επαληθευμένη ύλη, στόχους και ενότητα «Πηγές:»** με ακριβείς πηγές/εκδόσεις/ημερομηνία/σχετικά σημεία. Η ίδια η AI αφήγηση **δεν** είναι πηγή.
3. GitHub → **Actions** → «SAEK — Independent second AI video review» → **Run workflow**. Συμπλήρωση: `course=01`, `chapter=1`, `mp4_url` (άμεση HTTPS διεύθυνση του εξαγόμενου MP4), `published_url` (ακριβής σύνδεσμος του τελικού βίντεο), `reference_path=video-reviews/references/01-01.md`. Η άμεση διεύθυνση MP4 πρέπει να είναι προσωρινή και να μην περιέχει μυστικά, διότι είναι ορατή στους διαχειριστές εκτέλεσης.
4. Το workflow απαιτεί GitHub Actions **Repository secret** `OPENAI_API_KEY` (Settings → Secrets and variables → Actions). Δεν γράφουμε κλειδί σε αρχεία, ιστοσελίδα ή συνομιλία. Η χρήση API μπορεί να έχει χρέωση.
5. Κατέβασμα του artifact `second-ai-video-review`. Αν η έκθεση γράφει `hold`, γίνεται διόρθωση και πλήρης επανέλεγχος. Αν γράφει `ai_pass_human_review_required`, **ακόμη δεν δημοσιεύεται**.
6. Με ανθρώπινη επιστημονική έγκριση, το αμετάβλητο report αποθηκεύεται ως `video-reviews/reports/01-01.json`. Τότε μόνο μπορεί να προστεθεί αντίστοιχη εγγραφή στο `saek-video-approvals.json`:
   ```json
   {
     "schemaVersion": 1,
     "approved": {
       "01-01": {
         "status": "approved",
         "url": "https://scrimba.com/explain/EXAMPLE",
         "videoSha256": "64 lowercase hex characters from the real MP4 report",
         "reportPath": "video-reviews/reports/01-01.json",
         "approvedBy": "Ονοματεπώνυμο υπευθύνου",
         "clinicalReviewer": "Ονοματεπώνυμο κατάλληλου κλινικού ελεγκτή",
         "approvedAt": "2026-10-27"
       }
     }
   }
   ```
7. Το CI `SAEK — Block unapproved video publication` ελέγχει την εγγραφή, τη βαθμολογία, το SHA256 και ότι η πηγή δεν άλλαξε. Ο προβολέας εμφανίζει **μόνο** εγκεκριμένες καταχωρίσεις, με ακριβή αντιστοίχιση URL. Χωρίς μητρώο ή σύνδεση, παραμένουν κρυφές.

## Μεταφορά των 30 παλιών βίντεο

Οι σημερινές 30 διευθύνσεις βρίσκονται στο `saek-videos.js`. Το νέο `saek-video-approvals.json` είναι αρχικά **κενό**. Αν ενσωματωθεί το PR πριν ολοκληρωθεί ο έλεγχος, **και τα 30 υπάρχοντα βίντεο θα κρυφτούν**. Δεν αλλάζει ούτε διαγράφεται η γραπτή ύλη, οι ερωτήσεις ή η πρόοδος. Επιλέξαμε PR αντί άμεσης δημοσίευσης για να μη χαθεί απροειδοποίητα η πρόσβαση.

## Περιορισμοί και πρόσθετη προστασία

* Τα ανά 10 δευτερόλεπτα καρέ **δεν αποδεικνύουν** ότι κάθε εικόνα/καρέ είναι σωστό. Για κρίσιμες ιατρικές τεχνικές απαιτείται **ανθρώπινη παρακολούθηση όλου του βίντεο**.
* Ο εξαγόμενος MP4 SHA256 βεβαιώνει το αρχείο που ελέγχθηκε. **Δεν αποδεικνύει** ότι ο σύνδεσμος Scrimba παίζει για πάντα ακριβώς το ίδιο αρχείο: η πλατφόρμα μπορεί να αντικαταστήσει περιεχόμενο πίσω από URL. Χρειάζεται οπτική αντιπαραβολή και επανέλεγχος μετά από επεξεργασία.
* Η έκθεση AI είναι εισήγηση, **όχι πιστοποιητικό**. Κάθε απορία, αμφιβολία, επικίνδυνη επίδειξη ή θεραπευτικός ισχυρισμός απαιτεί καταγεγραμμένο έλεγχο από ειδικό.
* Οι ετικέτες «εγκεκριμένο» είναι **εσωτερική έγκριση** της εφαρμογής, όχι επίσημη έγκριση ΕΚΑΒ/ΣΑΕΚ.
* Για προστασία από χειροκίνητη παράκαμψη CI, ενεργοποίησε GitHub **branch ruleset** στο `main`: required pull request και required status check `video-publication-gate` (μετά την πρώτη επιτυχή εκτέλεση). Χωρίς ruleset, διαχειριστής μπορεί να γράψει απευθείας στο main.
