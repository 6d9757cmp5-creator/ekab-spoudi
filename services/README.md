# Κοινές υπηρεσίες της ΕΚΑΒ Σπουδή
Οι υπηρεσίες είναι **μία φορά** κοινές για όλα τα εργαλεία. Μη δημιουργείς δεύτερο αποθηκευτήριο σημειώσεων, δεύτερο cloud client, δεύτερο grader ή δεύτερο scheduler.

Το [μητρώο](registry.json) καταγράφει 23 υπαρκτά εργαλεία, υπηρεσίες και πηγές, με πραγματικές διαδρομές. «canonical» σημαίνει ότι το module έχει μεταφερθεί στο φάκελο ιδιοκτησίας του. «owner-mapped» σημαίνει **μόνο** καθορισμένο ιδιοκτήτη — ο ενεργός κώδικας παραμένει στις παλιές θέσεις. Αυτό δεν αποτελεί κλινική ή τεχνική πιστοποίηση.

- [Notes](notes/), [Sync](sync/): πραγματική μεταφορά του βασικού κώδικα και συμβατά re-export.
- [AI Grading](ai-grading/), [Progress](progress/), [Notifications](notifications/), [Search](search/), [Educational Media](educational-media/): ιδιοκτησία με υπάρχουσα ενεργή υλοποίηση στις αρχικές διαδρομές για να μη διαταραχθούν οι λειτουργίες.
- Τα [εργαλεία](../tools/) είναι χωριστές μαθητικές λειτουργίες, αλλά χρησιμοποιούν αυτές τις υπηρεσίες.

**Συμβατότητα:** Όλα τα `ekab.*` storage keys, Appwrite IDs, worker routes, root HTML URLs και ο κώδικας σύνδεσης παραμένουν αμετάβλητα.
