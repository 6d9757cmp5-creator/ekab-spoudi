# Ειδοποιήσεις — μία κοινή διεπαφή
Ενεργή υλοποίηση: `/ui-components/notification-center.js` και `.css`, καθώς και υπάρχον `/updates.js` για ενημερώσεις έκδοσης.
Παραμένουν στις ιστορικές θέσεις. Μη δημιουργείς δεύτερο notification center ανά εργαλείο ή background permission χωρίς συγκεκριμένη ανάγκη και συναίνεση. Προτιμώνται εντός εφαρμογής ειδοποιήσεις, keyboard access και χωρίς περιττά προσωπικά δεδομένα.
