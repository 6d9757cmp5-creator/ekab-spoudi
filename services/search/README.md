# Αναζήτηση και γλωσσάρι
Ενεργή υλοποίηση: `/global-tools.js`, `/search.html`, `/medical-terms.json`, `/saek-search-*.json`, `/app-pages-search-*.json`. Η προτεινόμενη ενότητα είναι ιδιοκτήτης για έρευνα & μελλοντική μεταφορά.
Η αναζήτηση δημόσιας ύλης δεν περιλαμβάνει προσωπικές σημειώσεις ή ιδιωτικές εγγραφές. Υποχρεωτική ελληνική ορολογία και ξεχωριστή επιστημονική τεκμηρίωση.
