# Εκπαιδευτικά πολυμέσα
Ενεργά scripts: `/educational-animation-engine.js`, `/educational-animation-sources.js`. Worker runtime: `/workers/educational-animation/` παραμένει στον deployable φάκελό του.
Η προτεραιότητα είναι τεκμηριωμένη ύλη, ελληνικές ετικέτες, προσβασιμότητα, άδεια/προέλευση αρχείων, graceful fallback και όρια στο AI κόστος. Δεν δηλώνουμε ότι ένας worker έχει ενεργοποιηθεί ή έχει μηδενική χρέωση χωρίς επίσημο deploy/billing evidence.
