# 3D Ανατομία — ανεξάρτητο εργαλείο

**Ενεργός κώδικας:** `tools/anatomy-3d/` (viewer, Ελληνική ορολογία, responsive CSS, tests, σύνδεση κεφαλαίων ΣΑΕΚ). Η ιστορική δημόσια διεύθυνση `ui-tools/anatomy-3d/index.html` παραμένει ενεργή και φορτώνει τα νέα αρχεία με κανονικές σχετικές διαδρομές. Δεν διαγράφουμε παλιά αρχεία όσο υπάρχουν πιθανές παλιές αναφορές, αλλά ο viewer δεν τα εκτελεί πλέον.

Το εκπαιδευτικό περιεχόμενο/μεταφράσεις και ο σχετικός επιστημονικός έλεγχος παραμένουν αμετάβλητα. Πολλές ελληνικές αντιστοιχίσεις απαιτούν ακόμη αξιολόγηση· το 3D atlas δεν προορίζεται για διάγνωση.

**Δοκιμές:** `node tools/anatomy-3d/test-greek-names.mjs`, `node scripts/verify-specialized-tools.mjs`, browser tests της παλιάς δημόσιας σελίδας.
