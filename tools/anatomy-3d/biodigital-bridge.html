Αδειοδοτημένο BioDigital

Αντέγραψε το URL από το Publish → Copy link / embed src. Δεν ζητούνται ούτε αποθηκεύονται API secrets. Ο σύνδεσμος Publish πρέπει να περιλαμβάνει την ταυτοποίηση Developer App που απαιτεί η BioDigital. Μόνο διευθύνσεις human.biodigital.com/viewer ή /widget γίνονται δεκτές.
Πώς δημιουργώ ένα μοντέλο ή εκπαιδευτική ξενάγηση;

Από την πλατφόρμα BioDigital αποθήκευσε ένα μοντέλο ή guided tour και χρησιμοποίησε τη λειτουργία Publish που διαθέτει το εξουσιοδοτημένο σχέδιό σου. Η παρούσα σελίδα δεν παρακάμπτει τους περιορισμούς του παρόχου.
