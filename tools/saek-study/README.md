# Μελέτη ΣΑΕΚ ΕΚΑΒ

Εργαλείο μαθημάτων, αναγνώστη και οπτικής εκπαίδευσης. Οι δημόσιες σελίδες saek.html και saek-course-01.html έως saek-course-20.html παραμένουν στη ρίζα, μαζί με τα ιστορικά assets, ώστε να μη χαλάσει η πρόσβαση των μαθητών. Κάθε μετακίνηση κώδικα εδώ θα συνοδεύεται από έλεγχο διαδρομών, εικόνων και ελληνικών όρων.
