# Κατάλογος AED και επαφών
Ιδιοκτησία `/contacts.html`, `/contacts-nearby-aed.js`, `/contacts-aed.css`. Ενεργός κώδικας παραμένει στη root για να κρατηθεί η υπάρχουσα πλοήγηση.
Οι θέσεις AED απαιτούν επαλήθευση/ημερομηνία ενημέρωσης πριν χρησιμοποιηθούν ως πραγματικές οδηγίες επείγουσας ανταπόκρισης. Όχι συλλογή ακριβούς τοποθεσίας χωρίς σαφή απαίτηση και άδεια χρήστη.
