# Πρόγραμμα ημέρας και επαναλήψεις
Εργαλείο οργάνωσης μελέτης: `/study_map.html`, `/study-resume.js`, `/study-scheduler.js`. Τα κοινά δεδομένα, IndexedDB και activity time ανήκουν στις [services/progress](../../services/progress/).
Δεν κατασκευάζεται δεύτερος scheduler: το εργαλείο παρουσιάζει και αξιοποιεί τον υπάρχοντα μηχανισμό, με παλιές διευθύνσεις και keys αμετάβλητα.
