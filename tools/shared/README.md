# Κοινές υπηρεσίες κεντρικής εφαρμογής

Η αρχική index.html, app.js, navigation.js, sw.js, οι υπηρεσίες σύνδεσης και ο συγχρονισμός παραμένουν **στη ρίζα**. Κανένα εργαλείο δεν δημιουργεί δεύτερο login, δεύτερο service worker ή δεύτερη αποθήκη μαθητικών δεδομένων.

Η κοινή πλοήγηση πέντε προορισμών (`Αρχική`, `ΣΑΕΚ`, `ΕΟΠΠΕΠ`, `Αποστολές`, `Εργαλεία`) υλοποιείται μία φορά από το root `navigation.js`, χωρίς επιπλέον service worker ή login. Η ονομασία των αρχείων εισόδου `mentor-next.html` και `mentor-protocol-suite.html` παραμένει σταθερή για συμβατότητα.
