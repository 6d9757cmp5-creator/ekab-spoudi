# MENTOR OS — ψηφιακός εκπαιδευτής

Ο φάκελος ιδιοκτησίας του MENTOR OS είναι εδώ. **Ενεργός ιστορικός κώδικας:** [mentor/](../../mentor/), ήδη οργανωμένος σε presence, avatar, voice, ai, core και app. Δεν δημιουργούμε δεύτερο αντίγραφο των εκατοντάδων εξαρτήσεων.

Είσοδος: [mentor-lab.html](../../mentor-lab.html). Ο MENTOR εμφανίζεται ως ψηφιακός εκπαιδευτής, δίνει οδηγίες και debrief αλλά **δεν είναι ιδιοκτήτης των GLB ασθενών ή της φυσιολογίας**. Αυτά ανήκουν στον [Προσομοιωτή](../patient-simulator/). Η σύνδεση γίνεται μέσω mentor:context event.

Η μελλοντική μεταφορά των υπόλοιπων MENTOR modules από το ιστορικό mentor/ απαιτεί πλήρεις ελέγχους παλιών URLs και bundles.
