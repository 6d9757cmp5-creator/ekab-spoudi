# ΕΚΑΒ Σπουδή — ανεξάρτητα εργαλεία

Η κεντρική εφαρμογή και τα δημόσια HTML entrypoints παραμένουν **στη ρίζα** ώστε να μη σπάσουν οι σύνδεσμοι GitHub Pages.

| Εργαλείο | Φάκελος ιδιοκτησίας | Ενεργές θέσεις |
|---|---|---|
| Προσομοιωτής Ασθενών | [patient-simulator](patient-simulator/) | Canonical app, core, tests, 3D assets όλα μέσα σε αυτόν |
| MENTOR OS | [mentor-os](mentor-os/) | Υφιστάμενος ενεργός φάκελος mentor/ για compatibility |
| Ελληνικά Πρωτόκολλα | [protocol-lab](protocol-lab/) | protocols.html, mentor-protocol-suite.html |
| ΣΑΕΚ | [saek-study](saek-study/) | saek.html και σελίδες μαθημάτων |
| ΕΟΠΠΕΠ | [eoppep-exams](eoppep-exams/) | eoppep.html, written_exam.html |
| Κοινή εφαρμογή | [shared](shared/) | index.html, navigation.js, app.js, sw.js |

**Κανόνας ανάπτυξης:** Κάθε καινούργιος κώδικας/asset ανήκει σε ένα εργαλείο. Το MENTOR OS παρέχει καθοδήγηση, ο Προσομοιωτής Ασθενών διαχειρίζεται τους ασθενείς και τη σκηνή. Συνδέονται μέσω του event mentor:context, όχι αντιγράφοντας κώδικα. Οι άλλες root λειτουργίες δεν μετακινούνται χωρίς ξεχωριστή έγκυρη δοκιμή και wrappers. Δες τα README κάθε φακέλου.

## Ονοματοδοσία στην εφαρμογή

- **MENTOR OS**: αποκλειστικά ο ψηφιακός εκπαιδευτής, η παρουσία, η βοήθεια και η καθοδήγησή του.
- **Προσομοιωτής Ασθενών**: οι εικονικοί ασθενείς, 3D σκηνές, συνθετικά ζωτικά και περιστατικά. Ιδιοκτησία `tools/patient-simulator/`. Το ιστορικό URL `mentor-next.html` μένει ανέπαφο.
- **Protocol Lab / Ανασκόπηση Πρωτοκόλλου**: η εφαρμογή ασκήσεων πρωτοκόλλων ανήκει στο `tools/protocol-lab/`. Ο MENTOR μπορεί να δίνει συνοδευτική βοήθεια, αλλά δεν αποτελεί το όνομα του εργαλείου.
- **Εργαστήριο ΗΚΓ (ECG Lab)**: ανεξάρτητη συνθετική εξάσκηση στο `tools/ecg-lab/`. Το παλιό URL `mentor-ecg.html` και το shim `mentor-ecg.js` διατηρούνται· ο MENTOR μπορεί να συνοδεύει την εξάσκηση, δεν διαχειρίζεται τον ECG generator.
- **Εξετάσεις ΣΑΕΚ / ΕΟΠΠΕΠ**: διατηρούν δικές τους λειτουργίες, ιστορικό και βαθμολογία. Η υποστήριξη MENTOR είναι προαιρετική.
- **3D Ανατομία**: ανεξάρτητος ανατομικός άτλας, όχι τμήμα του Προσομοιωτή Ασθενών.

Οι παλιές διαδρομές, selectors, API ονόματα και κλειδιά `localStorage` δεν μετονομάζονται κατά την αλλαγή ετικέτας. Η ενιαία πλοήγηση προέρχεται από το υπάρχον κοινό `navigation.js`· η αρχική οθόνη διαθέτει τέσσερις κύριες εκπαιδευτικές διαδρομές και έναν συγκεντρωτικό κατάλογο εργαλείων.
