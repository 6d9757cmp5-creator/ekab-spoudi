# Βιβλιοθήκη PDF
Ιδιοκτησία: `/pdf-library.html`, `/pdf-library.js`, σχετικό `reader.js` και assets. Η ενεργή υλοποίηση παραμένει στη ρίζα (**owner-mapped**, όχι ολοκληρωμένη μεταφορά).
Χρησιμοποιεί το μοναδικό υπάρχον cloud sync, όχι νέα βάση προσωπικών PDF. Ελέγχουμε μέγεθος, τύπο αρχείων, ιδιωτικότητα, προσβασιμότητα αναγνώστη.
