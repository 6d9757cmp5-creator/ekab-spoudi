# ATLA — Καθημερινός έλεγχος νέας γνώσης (GitHub Actions)

**Σκοπός:** Να ανακαλύπτονται **κάθε ημέρα** νέες, σχετικές επιστημονικές δημοσιεύσεις και πιθανές αλλαγές στις ήδη καταχωρισμένες εκπαιδευτικές/βιβλιογραφικές πηγές, χωρίς χειροκίνητη αναζήτηση.

## Τι εκτελείται

- [GitHub Actions workflow](../../../.github/workflows/atla-daily-knowledge-refresh.yml): `schedule: 17 2 * * *` (02:17 UTC· περίπου 04:17 χειμώνα / 05:17 καλοκαίρι στην Ελλάδα). Υπάρχει και **Run workflow** για χειροκίνητο έλεγχο.
- [`scan.mjs`](scan.mjs): Node 22, χωρίς npm εξαρτήσεις, χωρίς κανένα κλειδί OpenAI/LLM, χωρίς εκτέλεση ή εγκατάσταση άγνωστου κώδικα.
- [`watchlist.json`](watchlist.json): 35 **πρόσθετες** υπάρχουσες πηγές από την προηγούμενη συγκέντρωση ATLA (13 νέες βιβλιογραφικές καταχωρίσεις, 8 εκπαιδευτικές πηγές, 14 κλινικές αναφορές). Ελέγχονται παράλληλα με όσα ήδη υπάρχουν στα πραγματικά μητρώα της τρέχουσας κύριας έκδοσης. Ίδια URL **αποδιπλοποιούνται**.
- Έλεγχος `HEAD` στα δηλωμένα HTTPS URLs εντός allowlist. Αλλαγμένο `ETag` ή `Last-Modified` σημαίνει **πιθανή αλλαγή σελίδας**, **όχι** αποδεδειγμένα νέα ιατρική γνώση.
- PubMed μέσω επίσημων **NCBI E-utilities**: τελευταίες 30 ημέρες, θεματικές *προνοσοκομειακή φροντίδα, αναζωογόνηση, τραύμα*, με στόχευση κατευθυντήριων οδηγιών/συστηματικών ανασκοπήσεων. Καταγράφονται μόνον **τίτλος, πηγή, ημερομηνία, PMID, σύνδεσμος και κατηγορία**.
- Δοκιμές στο `scan.test.mjs` πριν από κάθε εκτέλεση, έπειτα έλεγχος ότι **όλες** οι νέες αναφορές είναι `pending-review`. Σε αποτυχία η εκτέλεση δεν δημοσιεύει ιατρικό υλικό.

## Παραδοτέα εργασίας

Τα ακόλουθα αρχεία γράφονται/ενημερώνονται **μόνον από τη scheduled/manual εργασία μετά τους ελέγχους**:

| Αρχείο | Περιεχόμενο |
| --- | --- |
| `queue/last-scan.json` | Πότε έγινε ο έλεγχος, πόσα URLs ελέγχθηκαν, νέα papers και αστοχίες. |
| `queue/source-health.json` | Αποτελέσματα HTTP/validators ανά επίσημη πηγή. |
| `queue/pending-pubmed.json` | Μέχρι 100 υποψήφιες νέες επιστημονικές αναφορές, για ανεξάρτητη εξέταση. |

Η εργασία ενημερώνει μόνο **αυτή** την ουρά με `github-actions[bot]` και δημιουργεί 14ήμερο artifact αποτελεσμάτων. Δεν αγγίζει ύλη, βαθμούς, προσωπικά δεδομένα, δεδομένα ασθενών ή την ενεργή βιβλιοθήκη AI.

## Όριο εξουσιοδότησης — κρίσιμο

**Ανακάλυψη ≠ γνώση έτοιμη προς διδασκαλία.** Για να χρησιμοποιήσει ο ATLA AI μια νέα πληροφορία χρειάζονται κατά σειρά: τεκμηριωμένη προέλευση και έκδοση → δικαίωμα/άδεια για το συγκεκριμένο αρχείο και τρόπο χρήσης → ανάγνωση πραγματικού υλικού → αντιστοίχιση σε μάθημα/στόχο ΣΑΕΚ και ελληνικές αρμοδιότητες → επιστημονική επιμέλεια και ανεξάρτητοι έλεγχοι → ενεργοποίηση σε βιβλιογραφικά τεκμηριωμένο σύστημα ανάκτησης (RAG). Τα αυτόματα τεστ **δεν υποκαθιστούν** τον τελευταίο έλεγχο.

Η Ιατρική παραμένει εσωτερική εξειδικευμένη γνώση του ATLA AI, **όχι ξεχωριστός τομέας για τον μαθητή**. Η παρούσα έκδοση δεν κάνει LLM fine-tuning, δεν προσθέτει αυτόματα κλινικά πρωτόκολλα, δεν κατεβάζει ολόκληρα εμπορικά βιβλία, και δεν ενεργοποιεί αυτόματα RAG.

**Κατάσταση ενεργοποίησης:** η ύπαρξη workflow στο `main` επιτρέπει την προγραμματισμένη εκτέλεση *εφόσον το GitHub Actions είναι ενεργοποιημένο και επιτρέπεται το `contents:write`*. Η πραγματική πρώτη εκτέλεση, η επιτυχία των CI checks και η δημιουργία ουράς πρέπει να επιβεβαιωθούν από τα Actions και από τα παραγόμενα αρχεία, όχι από μόνη την καταχώριση του workflow.
