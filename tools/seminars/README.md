# Προετοιμασία Σεμιναρίων — ανεξάρτητο εργαλείο

Η δημόσια `/seminar-prep.html` παραμένει στη ρίζα. Το πραγματικό εκπαιδευτικό υλικό `seminar-tracks.js`, ο χειριστής `seminar-prep.js` και η εμφάνιση `seminar-prep.css` φορτώνονται από `tools/seminars/` χωρίς αλλαγή σειράς.

Η κοινή υπηρεσία `seminar-sync.js`, η βαθμολόγηση AI και οι κεντρικές υπηρεσίες λογαριασμού/συγχρονισμού **δεν αντιγράφονται** στο εργαλείο· παραμένουν κοινά services. Οι προηγούμενες root εκδόσεις των τριών classic JS/CSS διατηρούνται προσωρινά για legacy URLs, αλλά δεν εκτελούνται στο σημερινό seminar-prep.html.

Το πρόγραμμα είναι δοκιμαστική προετοιμασία, όχι επίσημη πιστοποίηση ERC. Δεν τροποποιήθηκαν ερωτήσεις, απαντήσεις ή κλειδιά προόδου.

**Δοκιμές:** `node scripts/test-seminar-sync.cjs`, `node scripts/verify-specialized-tools.mjs` και browser smoke.
