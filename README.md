# ΕΚΑΒ Σπουδή v19 — καθαρό περιβάλλον ΕΟΠΠΕΠ

## Πλοήγηση
- **Θεωρία ΕΟΠΠΕΠ (`index.html`)**: Επίσημη τράπεζα 314 ερωτήσεων (105 Ομάδα Α, 209 Ομάδα Β) και πρόοδος ανά ομάδα στην ίδια κεντρική κάρτα.
- **Πρακτικό ΕΟΠΠΕΠ (`practical_exam.html`)**: Ακριβείς εικόνες των πρωτότυπων σελίδων 17–18 από το υποβληθέν επίσημο PDF, με μεγέθυνση και πλήρες offline PDF.
- **Κατάρτιση ΣΑΕΚ (`saek.html`)**: Εντελώς ανεξάρτητη καρτέλα για τα μαθήματα των τεσσάρων εξαμήνων.

Οι θεματικές στο `index.html` είναι δική μας βοηθητική κατηγοριοποίηση, **όχι επίσημες ομάδες ΕΟΠΠΕΠ**. Ανοίγουν μόνο με πάτημα (πτυσσόμενη ενότητα). Ο επίσημος κατάλογος έχει μόνο Ομάδα Α και Β, καθώς και χωριστό πρακτικό μέρος.

## Πηγές στις ερωτήσεις
- Κάθε θέμα εμφανίζει επάνω σύνδεσμο στο **πρωτότυπο PDF** (τοπικό `eoppep-source.pdf#page=N`).
- Το σήμα κατάστασης λύσης επάνω από την ερώτηση είναι κουμπί. Ανοίγει παράθυρο με πρωτότυπη σελίδα, βιβλιογραφική πηγή, κατάσταση επαλήθευσης, ειδικές εκκρεμότητες.
- Η λύση επαναλαμβάνει τους ενεργούς συνδέσμους παραπομπών.
- Αν το Safari αγνοεί την παράμετρο `#page=N`, ο χρήστης μπορεί να πλοηγηθεί χειροκίνητα στο PDF. Για το πρακτικό μέρος παρέχονται επιπλέον ορατές εικόνες των ίδιων σελίδων.

## Δημοσίευση χωρίς πληρωμή
Ανεβάστε τα περιεχόμενα του ZIP (όχι το ZIP) **στη ρίζα** του ίδιου GitHub Pages repository. Σε Settings → Pages επιβεβαιώστε δημοσίευση από την αντίστοιχη branch / root. Ανοίξτε το site από Safari και επιλέξτε Κοινή χρήση → Προσθήκη στην οθόνη Αφετηρίας. Το GitHub Pages απαιτεί δημοσίως προσβάσιμο repository στην τυπική δωρεάν ρύθμιση.

## Μεταφορά προόδου
Η αποθήκευση `localStorage` διατηρεί ακριβώς το κλειδί `ekab-eoppep-official-v15`, δηλαδή δεν διαγράφεται κατά την αναβάθμιση εφόσον δεν αλλάζει η διεύθυνση/προέλευση του site και δεν καθαρίζεται ο χώρος δεδομένων. Γίνονται δεκτά αντίγραφα προόδου v15–v19. Η εφαρμογή δεν εισάγει PDF/ZIP από τον χρήστη, σύμφωνα με τη ρητή επιλογή.

## Επιστημονικό όριο
244 από 314 απαντήσεις είναι εκπαιδευτικές συνθέσεις με βιβλιογραφία, εκ των οποίων μόνο 8 είχαν ειδική διασταύρωση με συγκεκριμένα σημεία πηγών στη v18. Οι υπόλοιπες 236 απαιτούν αναλυτικό έλεγχο ανά ισχυρισμό. 70 προσχέδια **δεν βαθμολογούνται** και ζητούν ειδική επαλήθευση. Καμία δεν αποτελεί επίσημο λυσάρι ή υπηρεσιακό πρωτόκολλο χορήγησης φαρμάκων. Η ισχύουσα μορφή εξέτασης πρέπει να επιβεβαιώνεται από τη συγκεκριμένη ανακοίνωση του ΕΟΠΠΕΠ.

## Έλεγχος
Δοκιμάστηκαν σε απομονωμένο Chromium οι μετρητές, οι επίσημες ομάδες, η πτυσσόμενη θεματική ανάλυση, η μελέτη, τα φίλτρα, το modal πηγών, η πληκτρολόγηση και η αυτοαξιολόγηση. Έγινε έλεγχος σύνταξης JS και συνοχής αρχείων. Δεν ολοκληρώθηκε live δοκιμή GitHub Pages/iPhone στον λογαριασμό του χρήστη.

Δεν χρειάζεται PDF για βασική ανάγνωση και λειτουργεί offline μετά την πρώτη φόρτωση των σελίδων. Πηγή προγράμματος Οδηγός Κατάρτισης ΣΑΕΚ 2024. Οι πλήρεις εκτενείς σημειώσεις δεν έχουν ακόμη ολοκληρωθεί. Στο πρακτικό, οι εικόνες 17–18 είναι πλέον το μόνο στοιχείο μεγέθυνσης.
