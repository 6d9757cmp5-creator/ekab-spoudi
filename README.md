# ΕΚΑΒ Σπουδή v15 — ΟΛΕΣ οι 314 αυθεντικές ερωτήσεις του παραδοθέντος καταλόγου

Η v15 χρησιμοποιεί το πρωτότυπο αρχείο `Εοπεπ(1).pdf` της βιβλιοθήκης του χρήστη, 18 σελίδες, για την ειδικότητα «Διασώστης – Πλήρωμα Ασθενοφόρου» (νέου τύπου).

- 105 γενικές + 209 ειδικές = 314 αριθμημένες αυτούσιες ερωτήσεις ανάπτυξης.
- 16 ερωτήσεις διαθέτουν **ενδεικτική τεκμηριωμένη εκπαιδευτική λύση** (όχι επίσημο λυσάρι).
- 298 δεν διαθέτουν τεκμηριωμένη λύση. Δίνεται κείμενο ερώτησης, δυνατότητα γραπτής απάντησης και επανάληψης, **χωρίς αυτόματη βαθμολόγηση**.
- Αρχεία `official_questions.json`, `index.html`, `practical_exam.html`, `supplementary_practice.html`.
- Πρόοδος ανά Ομάδα Α/Β και βοηθητική θεματική, 5 συνεχόμενες *αυτοαξιολογήσεις* σωστής απάντησης σε ερωτήσεις με λύση.
- Παλιές 121 μη επίσημες ασκήσεις παραμένουν σε **ξεχωριστή** οθόνη, δεν αυξάνουν επίσημη πρόοδο.
- Οι 314 ερωτήσεις διατίθενται ως ακριβές κείμενο του χρήστη για ιδιωτικό έλεγχο· πριν από δημόσια διάθεση χρειάζεται έλεγχος όρων αναπαραγωγής.
- Η έκδοση του 18σέλιδου καταλόγου δεν ταυτοποιήθηκε ανεξάρτητα με νεότερη ημερομηνία δημοσίευσης, επομένως ελέγχεται ο ισχύων κατάλογος όταν ανακοινωθεί εξεταστική περίοδος.

### iPhone / GitHub Pages
Αποσυμπίεσε το ZIP και ανέβασε όλα τα αρχεία στη ρίζα του GitHub repository. Στο Safari άνοιξε το ενεργό GitHub Pages link και διάλεξε Κοινή χρήση > Προσθήκη στην οθόνη αφετηρίας. Αντικατάσταση του περιεχομένου του ίδιου URL διατηρεί συνήθως την πρόοδο στην ίδια συσκευή/ιστότοπο. Εξήγαγε αντίγραφο προόδου πριν από αλλαγές.
