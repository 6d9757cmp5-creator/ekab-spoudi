# ΕΚΑΒ Σπουδή v11 — προδημοσιευτική έκδοση περιεχομένου

**121 συνολικές ερωτήσεις**, από τις οποίες 10 είναι εκπαιδευτικές αναδιατυπώσεις από συγκεκριμένα θέματα της **πιλοτικής** επίσημης τράπεζας Υπουργείου. Οι υπόλοιπες είναι τεκμηριωμένες πρωτότυπες ερωτήσεις, όχι αυτούσια θέματα ΕΟΠΠΕΠ.

- Πρώτη προτεραιότητα η εξέταση ΕΟΠΠΕΠ: προσαρμοστική επανάληψη, 5 συνεχόμενες σωστές, κύκλος κάλυψης, πρόοδος ανά ενότητα.
- Φαρμακολογία: 11 τεκμηριωμένες κάρτες στο `farmaka.html`, με διαχωρισμό ένδειξης/οδού/δόσης και προειδοποιήσεις.
- ΣΑΕΚ: πίνακας 20 μαθημάτων από τον επίσημο οδηγό στο `saek.html`.
- Μη τεκμηριωμένο υλικό: `NOT_VERIFIED.md`.
- Ασφαλής ενημέρωση: ανέβασε όλα τα αρχεία στη ρίζα του ΙΔΙΟΥ GitHub repository, Settings > Pages. Μην αλλάξεις URL. Πριν από ενημέρωση πάρε αντίγραφο προόδου.
- Δεν χρειάζεται να ανεβάσεις το ZIP μέσα στην εφαρμογή.
- Δεν έχει γίνει ανεξάρτητη έγκριση καθηγητή/κλινικού ειδικού.
