# ΕΚΑΒ Σπουδή — δωρεάν PWA (πρώτη έκδοση)

Περιλαμβάνει: μία ερώτηση τη φορά, βαθμολογία, φίλτρα ανά ενότητα, προσαρμοστική επανάληψη (τα λάθη εμφανίζονται συχνότερα και οι διαδοχικές επιτυχίες σπανιότερα), αποθήκευση μόνο στη συσκευή, λειτουργία offline μετά από πρώτη φόρτωση, εισαγωγή τράπεζας ερωτήσεων JSON και εξαγωγή στατιστικών.

**Σημαντικό:** Οι 3 προεγκατεστημένες ερωτήσεις είναι ΕΝΔΕΙΚΤΙΚΕΣ, όχι αντιγραφή ή επιβεβαίωση της τράπεζας ΕΟΠΠΕΠ. Μη χρησιμοποιήσεις την εφαρμογή ως πλήρη ύλη πριν εισαγάγεις επαληθευμένες ερωτήσεις και απαντήσεις.

## Δωρεάν δημοσίευση στο GitHub Pages
1. Δημιούργησε δωρεάν λογαριασμό στο https://github.com
2. Φτιάξε νέο **public** repository (π.χ. `ekab-spoudi`).
3. Ανέβασε τα `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` στη ρίζα του repository.
4. Settings → Pages → Build and deployment → Deploy from a branch → Branch `main` / `root` → Save.
5. Μόλις δημοσιευτεί, άνοιξε τη διεύθυνση `https://USERNAME.github.io/ekab-spoudi/` από Safari στο iPhone. Share → Add to Home Screen / Προσθήκη στην οθόνη Αφετηρίας.

Δωρεάν φιλοξενία από GitHub Pages υπό τους ισχύοντες περιορισμούς χρήσης. Δεν απαιτείται App Store. Υποστηρίζεται ασφαλής σύνδεση HTTPS.

## JSON μορφή
```json
[
  {
    "id":"eoppep-001",
    "category":"BLS",
    "question":"Κείμενο ερώτησης",
    "options":["Επιλογή Α", "Επιλογή Β", "Επιλογή Γ"],
    "answer":0,
    "explanation":"Τεκμηριωμένη επεξήγηση της σωστής επιλογής"
  }
]
```
`answer` είναι δείκτης από το 0 (0=πρώτη επιλογή). **Μην εισάγεις μη επιβεβαιωμένες απαντήσεις.**

Η αποθήκευση γίνεται με `localStorage`. Αν ο χρήστης διαγράψει δεδομένα ιστοτόπου, αν αλλάξει browser/συσκευή ή τοποθεσία φιλοξενίας, η πρόοδος δεν μεταφέρεται αυτόματα. Υπάρχει κουμπί εξαγωγής στατιστικών, όχι ακόμα εισαγωγής τους. Δεν είναι κρυπτογραφημένη αποθήκευση.
