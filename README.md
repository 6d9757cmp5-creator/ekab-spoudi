# ΕΚΑΒ Σπουδή — Επαληθευμένη αρχική έκδοση

**Αυτή δεν είναι η πλήρης εφαρμογή.** Περιλαμβάνει 8 θεμελιωμένες σε ERC 2025 ερωτήσεις, σαφή βιβλιογραφική παραπομπή ανά ερώτηση, προσαρμοστική επανάληψη λαθών, στατιστικά, εξαγωγή προόδου, σύνδεσμο επίσημου οδηγού, και εισαγωγή JSON. Τα εισαγόμενα δεδομένα από τον χρήστη δεν ελέγχονται επιστημονικά από το πρόγραμμα.

Για δωρεάν εγκατάσταση: Ανέβασε όλα τα αρχεία του φακέλου στη **ρίζα** public GitHub repository. GitHub → Settings → Pages → Deploy from a branch → main/(root). Άνοιξε το HTTPS URL από Safari στο iPhone → Share → Add to Home Screen. Δεν χρειάζεται Apple Developer Account.

Το `NOT_VERIFIED.md` είναι η ρητή λίστα όσων **δεν** ενσωματώθηκαν. Η ύλη θα πρέπει να εγκριθεί από τον εκπαιδευτή πριν από οποιαδήποτε δημόσια εκπαιδευτική χρήση. Τοπική πρόοδος μέσω localStorage· αν διαγραφούν τα δεδομένα Safari θα χαθεί η πρόοδος. Δεν υπάρχει λογαριασμός/cloud.

Ο νέος ενεργός κύκλος κάλυψης εμφανίζει όλες τις ερωτήσεις της επιλεγμένης ενότητας πριν επιτρέψει επανάληψη. Η προτεραιότητα λαθών εφαρμόζεται μέσα στον κύκλο. Μπορεί να απενεργοποιηθεί. Η τράπεζα παραμένει 8 εκπαιδευτικές ερωτήσεις ERC, όχι επίσημα θέματα ΕΟΠΠΕΠ.
