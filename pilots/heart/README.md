# ΣΑΕΚ — Πιλοτικό 3D μάθημα Ανατομίας (ΔΕΝ ΕΧΕΙ ΔΗΜΟΣΙΕΥΤΕΙ)

**Ένταξη στην ύλη:** \`saek-course-01.html#lesson-10\` «Καρδιά, μεγάλα αγγεία και βαλβίδες». Πρώτο οπτικό μικροκεφάλαιο: **Θέση της καρδιάς στον θώρακα**.

**Ασφάλεια:** Καμία αλλαγή στον κύριο Educational Animation ENGINE ή σε \`VIDEO_GENERATION_ENABLED=false\`. Το preview είναι ανεξάρτητο και ΔΕΝ δημιουργεί δημοσιεύσιμο βίντεο ή κλινική έγκριση. Δεν παρουσιάζει προσομοίωση καρδιακού παλμού, φυσιολογία βαλβίδων ή προνοσοκομειακό πρωτόκολλο.

**Υλοποίηση:** 
- Blender: εισαγωγή αυθεντικών HRA v1.2 GLB από τον ήδη υπάρχοντα κοινό κατάλογο και αληθινή 3D κίνηση κάμερας/μοντέλου· εξαγωγή 60 καρέ. Χωρίς παραμορφώσεις οργάνων.
- Remotion: ελληνικές επεξηγήσεις, χρονοσειρά σκηνών, MP4.
- Three.js: τοπική διαδραστική διερεύνηση (προσθήκη viewer απαιτεί ξεχωριστή δοκιμή browser).
- Educational Animation ENGINE: δοκιμαστικό record \`pilot-status.json\` με \`review\`, approvals false, URL null. Δεν τροφοδοτεί publisher.

## Κριτήρια
1. Πραγματικά τρισδιάστατα ανατομικά μοντέλα εισάγονται Blender, όχι εικόνες.
2. Ελέγχεται οπτικά η σωστή ευθυγράμμιση καρδιάς/πνευμόνων (ίδια HRA version).
3. Εξαγωγή πραγματικών καρέ και σύνθεση MP4 με Remotion.
4. Δεν εμφανίζεται στη ζωντανή ΣΑΕΚ, δεν αλλάζει ιστορικό προόδου/βαθμούς/νέα μαθήματα.
5. Χρειάζεται ανεξάρτητος επιστημονικός έλεγχος, ορθότερη ελληνική αφήγηση, επιβεβαίωση μοντέλων σε ανατομική απεικόνιση και έγκριση πριν από οποιαδήποτε ενσωμάτωση.

Attribution: Browne et al. 2022; model data HuBMAP CCF Human Reference Atlas.
