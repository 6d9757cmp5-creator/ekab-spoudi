# Πλήρες εκπαιδευτικό πιλοτικό βίντεο (ΜΗ ΔΗΜΟΣΙΕΥΜΕΝΟ)

Συνδέεται με Ανατομία Α΄ εξαμήνου, κεφάλαιο 10 (καρδιά, κοιλότητες, μεγάλα αγγεία, βαλβίδες). Παραγωγή με πραγματική HRA ανατομική γεωμετρία Blender, 3D προβολές και ελληνική συνθετική αφήγηση. Το εξαγόμενο MP4 είναι μόνο GitHub Actions artifact, όχι μέρος της εφαρμογής.

Τοπικό 3D μοντέλο δε χρησιμοποιείται ως επαληθευμένος καρδιακός φυσιολογικός προσομοιωτής. Η επεξήγηση ροής και βαλβίδων στο βίντεο είναι οπτική αναπαράσταση, όχι κλινικά επικυρωμένη animation φυσιολογίας.

Τα audio και timing παράγονται σε runtime από `prepare_audio.py` (Edge Greek synthetic TTS). Η μη διαθεσιμότητα της υπηρεσίας εμποδίζει το build· δεν υποκαθιστούμε με ακατάληπτη πρόχειρη φωνή.
